Video Software — DaVinci Resolve

Course Overview

This course introduces students to professional video editing, color correction, and audio post-production using DaVinci Resolve, the free industry-standard software from Blackmagic Design used on Hollywood films and TV shows. Students will learn the full post-production workflow: importing media, editing on a timeline, adding transitions and titles, correcting color, mixing audio, and exporting a finished video. DaVinci Resolve runs on Windows, macOS, and Linux.

Course Objectives

  • Install DaVinci Resolve and set up a project with correct frame rate and resolution.
  • Navigate the seven workspace pages: Media, Cut, Edit, Fusion, Color, Fairlight, and Deliver.
  • Import, organize, and manage media in bins and the media pool.
  • Edit video on a timeline using cuts, trims, transitions, and titles.
  • Apply basic color correction and simple color grading.
  • Edit and mix audio tracks using the Fairlight page.
  • Export a finished video for YouTube, social media, or local playback.

System Requirements

DaVinci Resolve 20 is free to download and use (a paid Studio version exists, but is not required for this course). It runs on Windows 10+, macOS 12.0+, and Linux. Minimum: 16 GB RAM recommended, a dedicated GPU with 2+ GB VRAM, and a fast storage drive (SSD preferred) for smooth video playback.

Web App Development

Course Overview

Now that you have learned HTML, CSS, and JavaScript, we will be combining all that together to make full webpages and web apps. You will learn how to combine files together into a structure that is standard across the industry. You will learn how to work in all three languages, and how to use them interact with each other.

This course is designed for students who have already done the Web Development 1 and 2 courses. If that is not the case, you should go back and go through them. This course assumes you have already learned all three languages.

Course Objectives

  • Gain foundational knowledge of web page file structure and interactions.
  • Learn how JavaScript, HTML, and CSS interact together.
  • Write code to create full websites and wep apps.

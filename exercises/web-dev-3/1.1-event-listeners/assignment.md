#### Practice

As an introduction to web application development, you'll create a simple interactive web app with a UI that runs in a web browser. The app you'll make is a game of emojis, player versus computer. The player will choose one of three emojis to play, in the hope of defeating the computer's randomly-chosen emoji. For this assignment, you'll practice DOM operations, including querying, manipulation, and event listeners, as well as functions and conditional logic. Do this by making rock, paper, scissors. 

-Design and implement a user interface that displays three emoji options and an emoji battlefield (Rock, Paper, Scissors).
-Use random logic to select the computer's choice, and conditional logic to decide the winner.
-Use addEventListener to respond to the player's emoji selection by presenting an emoji battle.
-Design and implement a unique way to visually reveal the winner after each play, including ties.
-The game should continue indefinitely, allowing the player to repeatedly select an emoji.
-Use several functions to separate each component of the game logic and UI implementation.
-Use querySelector to query elements and the textContent property to modify elements.

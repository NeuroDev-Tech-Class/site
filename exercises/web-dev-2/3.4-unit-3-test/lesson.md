### Description 
 As a follow-up to the previous JavaScript console program, you'll create an  interactive app that allows a user to manage a library of items. The example below is a  library of books, but you can choose a library of any people, places, or things that you  like. Some additional examples include friends, destinations, and songs. The app will  allow the user to add, remove, retrieve, and randomize items in the library. You'll also  validate user input to keep the data consistent. For this test, you'll practice input/output,  arrays, loops, conditionals, and functions. Refer to the example output below for an idea  of how the program might be presented to the user, but vary your messaging to be  appropriate for the library that you design. 

### Requirements 
 ■   When the program starts, prompt the user to choose from the menu options  listed below.  
 ■   The menu prompt should be repeated  forever  until the user explicitly chooses  to quit the program.  
 ■   Option 1:  list  . Display a list of all items currently  in the library, one per line.  Validation: the list must not be empty.  
 ■   Option 2:  add  . Prompt the user for a new item and  store it in the library.  Validation: the entry must not be empty.  
 ■   Option 3:  remove  . Prompt the user for an item and  remove it from the library.  Validation: the entry must exist.  
 ■   Option 4:  pick  . Randomly choose one item from the  library and present it.  Validation: the list must not be empty.  
 ■   Option 5:  quit  . Stop prompting the user to choose  a menu option and allow  the program to terminate.  
 ■   For each of the validation rules above, use the appropriate conditions to  inform the user when there's a problem.  
 ■   If a user enters a menu option that isn't one of the above, inform the user and  prompt for a new choice.  
 ■   Use the  console.log  function for console output and  the provided  prompt 
 function to collect user input.  
 ■   Create a separate function for each of the first four menu options, and a  main 
 function to run the menu loop.  
 ■   Create an array of strings to store the library's data, and use array operations  to implement each function. 

### Optional Challenges 
 ■   Add one or more additional menu options applicable to the library you design.  
 ■   Allow the user the enter more than one data attribute for each item in the  library.  
 ■   Add an easter egg, such as a hidden menu option that does something secret  or fun.  
 ■   Save the library items to a file and load the items from the file when the  program starts.

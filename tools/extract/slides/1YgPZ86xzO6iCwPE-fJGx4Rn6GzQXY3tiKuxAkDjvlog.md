## What does an operating system do?

Your operating system (OS) is the “system software” that manages all of the other programs on your computer.

You communicate back and forth with the OS through a user interface, and the OS in turn communicates with programs and hardware as needed.

---

## Graphical User Interface (GUI)

Uses graphics, icons, and other visual elements to help the user interact with programs. You use a mouse to click on icons, menus, and buttons. A GUI is more visually appealing and user-friendly than a CLI, but it can also be slower and less efficient for many tasks.

![Windows 10 desktop showing app icons and an open file explorer window](/images/slides/what-is-an-operating-system/04.webp)

---

## Command Line Interface (CLI)

Uses text-based commands which are typed into a terminal, like old-school computers. This offers more speed and utility and flexibility compared to a GUI. This can be intimidating for people who are new to computers, so it’s recommended for advanced users for specific tasks.

![Terminal window showing Ubuntu WSL with git status output](/images/slides/what-is-an-operating-system/05.webp)

---

## Application Programming Interface (API)

An API is how programs interact with the OS, allowing them to communicate and share resources. The OS acts as a middleman or interpreter between hardware and programs, eliminating the need for programmers to write lengthy code for each program. Instead, the OS handles common tasks, and apps aren't required to know any hardware specifics.

![Diagram showing User, Application, Operating System, and Hardware stacked in layers](/images/slides/what-is-an-operating-system/06.webp)

---

## Application Programming Interface (API)

For example, Microsoft Word doesn’t need to know how to print documents. It just sends data to the OS, which sends instructions to the printer. Programs like MS Word don’t need to take into account the thousands of different types of printers with different hardware, and printers don’t need to care about what programs are using them. This makes life easier for both users and programmers.

Video Production — DaVinci Resolve

Project Settings & Media Management

Configuring your project, importing footage, and organizing your media library

Setting Up a New Project

When you launch DaVinci Resolve, the Project Manager appears. This is where you create, open, and manage your projects. Click New Project, give it a descriptive name (e.g., "Highlight Reel v1"), and double-click to open it.

Before you start editing, take a moment to configure your Project Settings. Getting these right from the start saves headaches later.

Project Settings

Open Project Settings by clicking the gear icon in the bottom-right corner of the screen (available from any page).

Master Settings — Timeline Format

The most important settings are under Master Settings:

SettingWhat It DoesRecommended Value
Timeline ResolutionSets the pixel dimensions of your project1920 × 1080 for HD, 3840 × 2160 for 4K
Timeline Frame RateHow many frames per second your timeline usesMatch your footage (usually 24, 30, or 60)
Playback Frame RateFrame rate used for playback (should match timeline)Same as Timeline Frame Rate
Warning: The Timeline Frame Rate cannot be changed after you create your first timeline. Set it correctly before you begin editing. If your footage is 30 fps, set your timeline to 30 fps.
Tip: Not sure what frame rate your footage is? Import a clip into the Media Pool first, right-click it, and choose Clip Attributes to check. Or look at the clip's metadata in the Media page.

Other Useful Settings

  • Mismatched Resolution: Under Image Scaling > Input Scaling, set how Resolve handles clips that don't match your timeline resolution. "Scale full frame with crop" and "Scale entire image to fit" are the most common choices.
  • Working Color Space: For beginners, leave this at the default (DaVinci YRGB). As you advance, you can explore DaVinci YRGB Color Managed or ACES.
  • Optimized Media Resolution: If you plan to use proxy editing for performance, set this here (typically Half or Quarter resolution).

The Media Page

Switch to the Media page (first icon at the bottom, or Shift+2) to start importing and organizing your footage.

Importing Clips

There are several ways to bring media into your project:

  • Drag and drop: Open a file explorer window next to Resolve and drag files directly into the Media Pool.
  • File browser: Use the file browser on the left side of the Media page to navigate to your footage, then drag clips to the Media Pool.
  • Menu: Go to File > Import > Media (or press Ctrl+I) to open a standard file dialog.
  • Import entire folders: Right-click in the Media Pool and choose Import Media Folder to bring in the full contents of a folder, preserving its structure.

What You Can Import

DaVinci Resolve supports a wide range of formats:

  • Video: MP4, MOV, AVI, MKV, ProRes, DNxHD, and many more
  • Audio: WAV, MP3, AAC, FLAC, AIFF
  • Images: JPEG, PNG, TIFF, BMP, EXR (also image sequences)

Organizing with Bins

As your project grows, a flat list of clips becomes hard to navigate. Bins are folders inside the Media Pool that help you stay organized.

  • Right-click in the Media Pool and choose New Bin to create a folder.
  • Name your bins descriptively: Video, Audio, Music, Images, Sound Effects, B-Roll.
  • Drag clips into the appropriate bins.
  • You can nest bins inside bins for deeper organization.
Tip: A good bin structure might look like this: a top-level bin for each category (Video, Audio, Graphics), with sub-bins inside for specific scenes or types of content.

Metadata and Markers

Metadata is information attached to each clip — things like file name, resolution, frame rate, codec, duration, and creation date. You can view and edit metadata in the Metadata panel on the Media page.

You can also add your own metadata, like descriptions, scene numbers, or keywords. This is especially useful on larger projects where you need to find specific shots quickly.

Markers let you flag specific moments within a clip. Press M while viewing a clip to add a marker at the playhead position. You can color-code markers and add notes to them.

Smart Bins

Smart Bins are virtual bins that automatically collect clips based on metadata criteria. For example, you could create a Smart Bin that shows only clips with a resolution of 3840×2160, or only audio files, or only clips with a specific keyword.

To create a Smart Bin, right-click in the Smart Bins area (left sidebar of Media Pool) and choose Add Smart Bin. Set your filter criteria and Resolve will automatically populate it.

Power Bins

Power Bins are special bins that persist across all projects in your database. If you have assets you use in every project — like a logo, an intro animation, or a music track — put them in a Power Bin so they're always available without re-importing.

To show Power Bins, click View > Show Power Bins in the Media Pool.

Media Storage

At the top of the Media page, you'll find the Media Storage browser. This shows your computer's drives and lets you browse for footage without leaving Resolve. You can add frequently-used folders to your favorites for quick access under Preferences > Media Storage.

Warning: DaVinci Resolve does not copy your source files into the project. It links to them. If you move, rename, or delete your source files after importing, Resolve will lose track of them and show "Media Offline" errors. Keep your source files in a stable location and don't move them once you've started editing.

Media Management Best Practices

  • Create a project folder on your drive before you start. Put all your footage, audio, and images inside it.
  • Don't move source files after importing them into Resolve.
  • Use descriptive file names. interview_john_take2.mp4 is better than MVI_3842.mp4.
  • Back up your project folder regularly — external drive or cloud storage.
  • Use bins inside the Media Pool to mirror your folder structure.

Key Takeaways

  • Configure Timeline Resolution and Timeline Frame Rate in Project Settings before you start editing.
  • Import media through drag-and-drop, the file browser, or Ctrl+I.
  • Organize clips into bins for a clean, navigable Media Pool.
  • Smart Bins auto-organize by metadata; Power Bins persist across projects.
  • Never move or rename source files after importing — Resolve links to them, it doesn't copy them.

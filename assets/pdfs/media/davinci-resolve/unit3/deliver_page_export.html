Video Production — DaVinci Resolve

The Deliver Page & Exporting

Configuring render settings and exporting your finished video

The Deliver Page Layout

The Deliver page is the final step in your workflow — where your timeline becomes a video file you can share, upload, or archive. Switch to it by clicking the Deliver icon at the bottom of the screen (or Shift+8). The layout has three main areas:

  • Render Settings (left panel): Where you configure format, codec, resolution, quality, audio settings, and filename.
  • Timeline Preview (center): A viewer showing your timeline so you can set In/Out points if you only want to export a portion.
  • Render Queue (right panel): A list of jobs waiting to be rendered. You can queue multiple exports and render them all at once.

Using Presets

DaVinci Resolve provides built-in presets for common platforms. These automatically configure the optimal settings for you:

PresetSettings Applied
YouTubeMP4, H.264, 1080p or 4K, high quality
VimeoMP4, H.264, optimized for Vimeo's processing
TwitterMP4, H.264, settings within Twitter's limits
Audio OnlyExports just the audio track (WAV or AAC)
ProRes MasterHigh-quality ProRes for archiving or further editing

To use a preset, simply click it at the top of the Render Settings panel. The settings below will update automatically. You can still tweak individual settings after selecting a preset.

Tip: For most class projects, the YouTube preset at 1080p is the easiest choice. It produces a widely compatible MP4 file that works everywhere.

Custom Export Settings

If the presets don't fit your needs, you can configure everything manually under "Custom Export":

Format

The Format determines the container file type:

  • MP4 — The most universally compatible format. Recommended for virtually all web and sharing purposes.
  • QuickTime (MOV) — Common on macOS, supports ProRes codec for high-quality masters.
  • MKV — Open container format, less commonly used for delivery.

Codec

The Codec determines how the video is compressed:

  • H.264 — The standard codec for web video. Excellent compatibility (plays on every device and browser). Good quality at reasonable file sizes. This is your go-to choice.
  • H.265 (HEVC) — The successor to H.264. Produces smaller files at the same quality (or better quality at the same size). However, not all devices and browsers support it yet. Great if file size is important.
  • ProRes — High-quality professional codec. Large files. Use for masters or if you need to bring the file into another editing application.
  • DNxHD / DNxHR — Avid's professional codec. Similar use case as ProRes.

Resolution

Set the output resolution. It defaults to your timeline resolution. Common choices:

  • 1920 × 1080 (1080p Full HD) — Standard for most content
  • 3840 × 2160 (4K UHD) — For high-resolution delivery

Frame Rate

This should match your timeline frame rate. If your timeline is 30 fps, export at 30 fps.

Quality

You can control quality in two ways:

  • Automatic: Let Resolve choose the best bitrate. This usually produces good results.
  • Restrict to (bitrate): Set a maximum bitrate in kbps. For 1080p H.264, 10,000–20,000 kbps is a good range. For 4K, 30,000–50,000 kbps. Higher bitrate = larger file but better quality.

Audio Settings

Under the Audio tab in Render Settings:

  • Codec: AAC is the standard for MP4 files. Compatible everywhere.
  • Sample Rate: 48,000 Hz (48 kHz) is the standard for video. Don't change it unless you have a specific reason.
  • Bitrate: 192 kbps or 320 kbps for stereo audio.

Filename and Destination

At the top of the Render Settings panel:

  • Filename: Give your export a descriptive name (e.g., Highlight_Reel_v2_1080p).
  • Location: Click Browse to choose where the rendered file will be saved. Pick a folder you can easily find.

Render as Individual Clips vs. Single Clip

  • Single Clip: The entire timeline is exported as one continuous video file. This is what you want 99% of the time.
  • Individual Clips: Each clip on the timeline is exported as a separate file. Useful for batch processing or when you need individual shots.

Rendering

  1. Configure all your settings.
  2. Click Add to Render Queue. The job appears in the Render Queue panel on the right.
  3. You can add multiple jobs with different settings (e.g., a 1080p version and a 4K version) to the queue.
  4. Click Start Render (or Render All) to begin.
  5. A progress bar shows the render status. Rendering time depends on your project's length, resolution, effects, and your hardware (especially GPU).
Warning: Don't close DaVinci Resolve or put your computer to sleep while rendering. Let it finish completely. If a render fails, check the error message — common issues include insufficient disk space, unsupported codec, or missing media.

Quick Export

For a fast export without going to the Deliver page, use File > Quick Export from the Edit, Cut, or Color pages. A dialog appears with preset options (H.264 Master, YouTube, Vimeo, etc.). Select one, choose a filename and destination, and click Export. This is convenient for simple exports when you don't need custom settings.

Key Takeaways

  • The Deliver page has three areas: Render Settings (left), Timeline Preview (center), Render Queue (right).
  • Use presets (YouTube, Vimeo, etc.) for quick, optimized exports.
  • For custom exports: MP4 + H.264 is the safest, most compatible choice. Use H.265 for smaller files.
  • Set audio to AAC at 48 kHz.
  • Add to Render Queue then Start Render to export. Use Quick Export for simple one-click exports.

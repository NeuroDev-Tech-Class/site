Canvas, Resolution & File Formats

Setting Up Your Image and Saving It the Right Way

Creating a New Image

To create a new, blank image in GIMP, go to File > New (or press Ctrl+N). A dialog will appear where you configure the most important properties of your image before you start working.

Canvas Size

The canvas size is the width and height of your image, measured in pixels by default. Pixels are the tiny dots that make up a digital image. A few common starting sizes:

  • 1920 × 1080 px — Full HD screen resolution, great for desktop wallpapers and web graphics
  • 1080 × 1080 px — square format, commonly used for social media posts
  • 2550 × 3300 px — US Letter size at 300 DPI (8.5 × 11 inches), great for print

You can always change the canvas size later using Image > Canvas Size or scale the entire image with Image > Scale Image.

Resolution (DPI / PPI)

Resolution refers to how many pixels fit into one inch of printed output. It is measured in DPI (dots per inch) or PPI (pixels per inch) — for our purposes, these terms mean the same thing.

  • 72 DPI — the standard for web and screen display. Screens display images by pixel count, so DPI doesn't change how the image looks on screen, but it keeps the file size manageable.
  • 300 DPI — the standard for high-quality print. If you plan to print a poster, flyer, or photo, use 300 DPI so the result is sharp and detailed.
Tip: If your image is only going to be viewed on a screen (website, social media, presentation), 72 DPI is perfectly fine. Use 300 DPI only when the final output is physical print.

Color Space

GIMP works in the RGB color space by default — Red, Green, Blue. This is the standard for screens and digital images. Each pixel's color is defined by mixing different amounts of red, green, and blue light.

Fill Options

When creating a new image, GIMP asks what the background should be filled with:

  • White — a solid white background (most common)
  • Foreground Color — fills with whatever your current foreground color is
  • Background Color — fills with your current background color
  • Transparency — no background at all (shown as a gray checkerboard pattern). Use this when you're creating graphics like logos or icons that need a see-through background.

File Formats

Different file formats serve different purposes. Understanding when to use each format is an essential skill.

Format Extension Use Case Key Features
XCF .xcf GIMP project file Preserves all layers, masks, paths, and channels. Always save a copy in XCF while working.
PNG .png Web graphics, icons, logos Lossless compression (no quality loss). Supports transparency. Larger file size than JPEG.
JPEG .jpg / .jpeg Photos, web images Lossy compression (some quality lost to reduce file size). No transparency support. Great for photographs.
TIFF .tif / .tiff Print, archival Lossless compression. Very large file sizes. Preferred by print shops and professional workflows.
GIF .gif Simple animations, small web graphics Supports animation and transparency. Limited to 256 colors. Not suitable for photos.

Save vs. Export

GIMP makes an important distinction between saving and exporting:

  • File > Save (or Ctrl+S) — saves your project in GIMP's native XCF format. This preserves all layers, masks, paths, and editing history. Always save an XCF copy of your work.
  • File > Export As (or Ctrl+Shift+E) — exports your image to any other format (PNG, JPEG, TIFF, GIF, etc.). Exporting flattens your image into a single layer and may discard some data depending on the format.
Warning: If you only export as JPEG or PNG and never save the XCF file, you will lose all of your layers and non-destructive edits. Always Save the XCF file first, then Export a copy in the final format you need.

Workflow Summary

  1. Create a new image with File > New, choosing the right canvas size and resolution for your project.
  2. Work on your image using layers, tools, and filters.
  3. Save your project as an XCF file regularly (Ctrl+S).
  4. When finished, Export As the appropriate format (PNG for graphics with transparency, JPEG for photos, TIFF for print).
Tip: After exporting, GIMP's title bar will show the exported filename. Don't be confused — your working file is still the XCF. Use Ctrl+S to continue saving the XCF version.

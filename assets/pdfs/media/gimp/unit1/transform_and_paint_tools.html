Transform & Paint Tools

Moving, Reshaping, and Painting on Your Images

Transform Tools

Transform tools change the position, size, or shape of layers, selections, or paths. They are essential for compositing, layout, and fine-tuning your work.

Move (M)

Click and drag to move the active layer, selection, or path. In Tool Options, you can choose whether the Move tool moves the active layer or picks whichever layer you click on.

Align

Aligns or distributes layers relative to each other, to the canvas, or to a selection. Click a layer on the canvas to select it as the target, then use the alignment buttons in Tool Options (align left, center, right, top, middle, bottom).

Crop (Shift+C)

Draws a rectangle on the canvas and trims the image to that area. Press Enter to apply the crop. This permanently reduces the canvas size to your selection.

Rotate

Rotates a layer, selection, or path by a specified angle. Click and drag on the canvas to rotate interactively, or type an exact angle in the dialog that appears. Useful for straightening crooked photos or angling design elements.

Scale

Resizes a layer, selection, or path. Drag the corner handles to scale. Click the chain-link icon in the scale dialog to maintain the aspect ratio (proportional scaling). Use this to enlarge or shrink individual layers without affecting the whole image.

Shear

Shifts one side of a layer along the horizontal or vertical axis, creating a slanting or skewing effect. Useful for creating italic-style effects or perspective adjustments.

Perspective

Lets you drag the four corners of a layer independently, allowing you to simulate 3D perspective — for example, making text look like it's receding into the distance on a road or wall.

Flip

Mirrors a layer horizontally (left-right) or vertically (top-bottom). Toggle between horizontal and vertical flip in Tool Options.

Paint Tools

Paint tools let you apply color, erase, blend, and clone pixels directly on the canvas. Each tool behaves differently, but they all share common settings like brush size, opacity, and hardness.

Paintbrush (P)

The primary painting tool. Applies smooth strokes using the selected brush tip. Strokes can be soft or hard depending on the brush. Adjust opacity for a subtle, semi-transparent effect.

Pencil (N)

Similar to the Paintbrush, but always draws with hard edges — no anti-aliasing or softness. Every pixel is fully on or fully off. Ideal for pixel art or when you need crisp, precise lines at the pixel level.

Eraser (Shift+E)

Removes pixels from the active layer. If the layer has an alpha channel (transparency), the eraser makes pixels transparent. If there is no alpha channel, it paints with the background color instead. Adjust size and opacity like any other brush tool.

Airbrush (A)

Simulates a real airbrush — it applies paint gradually and builds up color the longer you hold the mouse in one spot. Great for smooth, gradual color transitions and shading.

Ink

Simulates an ink pen or calligraphy brush. The stroke width changes based on speed and direction, giving a natural hand-drawn feel. Good for inking and line art.

Clone Stamp (C)

Duplicates pixels from a source point to wherever you paint. To use it:

  1. Hold Ctrl and click to set the source point.
  2. Release Ctrl and paint somewhere else — the pixels from the source area are copied.

The Clone Stamp is essential for removing unwanted objects, fixing blemishes, and repairing damaged areas of a photo.

Healing Tool (H)

Works like the Clone Stamp, but blends the cloned pixels with the surrounding area for a seamless result. Set the source point the same way (Ctrl+click). Use the Healing Tool for skin retouching, scar removal, and subtle repairs where the Clone Stamp might look too obvious.

Smudge (S)

Pushes pixels around as if dragging your finger through wet paint. Useful for blending colors together and softening edges.

Blur/Sharpen

Blur mode softens the area you paint over; Sharpen mode increases contrast to make details crisper. Toggle between blur and sharpen in Tool Options. Useful for subtle, targeted adjustments.

Bucket Fill (Shift+B)

Fills a contiguous area of similar color with the foreground color, background color, or a pattern. Adjust the Threshold to control how similar adjacent pixels must be to get filled.

Gradient (G)

Click and drag to create a smooth transition between colors (or between a color and transparency). Choose from many gradient presets or create custom ones. The direction and length of your drag determines the gradient direction and transition range.

Brush Settings

Most paint tools share these essential settings in Tool Options:

  • Size — the diameter of the brush tip. Use [ and ] to quickly decrease or increase brush size.
  • Opacity — how opaque or transparent the stroke is (100% = fully solid).
  • Hardness — controls how soft or sharp the brush edges are (soft edges blend smoothly into the background).

Summary

  • Transform tools move, resize, rotate, and reshape layers and selections.
  • Paint tools apply or modify color directly on the canvas.
  • The Clone Stamp copies pixels from a source point; the Healing Tool does the same but blends seamlessly.
  • Adjust size, opacity, and hardness in Tool Options to control brush behavior.
  • Use keyboard shortcuts for faster workflow.

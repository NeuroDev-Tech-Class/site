The GIMP Interface

Finding Your Way Around GIMP's Workspace

Single-Window Mode vs. Multi-Window Mode

When you first open GIMP, it may launch with a single unified window or with multiple floating windows — depending on your version and settings. For beginners, Single-Window Mode is strongly recommended because it keeps everything in one organized window, similar to Photoshop.

To enable Single-Window Mode, go to Windows > Single-Window Mode in the menu bar. A checkmark will appear next to the option when it is active. GIMP remembers this setting between sessions.

Tip: If your GIMP interface looks confusing with separate floating panels, switch to Single-Window Mode right away. It makes learning much easier.

Interface Overview

In Single-Window Mode, the GIMP workspace is divided into several key areas. Let's walk through each one from left to right.

The Toolbox (Left Panel)

The Toolbox is a vertical panel on the left side of the screen containing icons for every tool in GIMP. These tools are organized into groups:

  • Selection tools — Rectangle Select, Ellipse Select, Free Select (Lasso), Fuzzy Select (Magic Wand), Select by Color, Scissors Select
  • Paint tools — Paintbrush, Pencil, Airbrush, Ink, Eraser, Clone, Healing, Smudge, Blur/Sharpen
  • Transform tools — Move, Align, Crop, Rotate, Scale, Shear, Perspective, Flip
  • Other tools — Paths, Text, Gradient, Bucket Fill, Color Picker (Eyedropper), Measure, Zoom

Each tool icon can be clicked to activate that tool. You can also hover over any icon to see its name and keyboard shortcut.

Tool Options (Below the Toolbox)

Directly below the Toolbox (or docked beneath it) is the Tool Options panel. This area changes dynamically based on which tool is currently selected. For example:

  • Select the Paintbrush and Tool Options will show brush size, opacity, hardness, dynamics, and spacing.
  • Select the Rectangle Select and Tool Options will show options for fixed size, feathering, rounded corners, and selection mode (replace, add, subtract, intersect).

Always check Tool Options when a tool isn't behaving the way you expect — the answer is usually in the settings.

Warning: If the Tool Options panel is missing, go to Windows > Dockable Dialogs > Tool Options to bring it back.

The Canvas (Center)

The large center area is the Canvas — this is where your image is displayed and where you do all of your actual editing work. You can zoom in and out using the + and - keys or by holding Ctrl and scrolling the mouse wheel. Use the Fit Image in Window command (Shift+Ctrl+J) to see the entire image at once.

The canvas is surrounded by rulers (in pixels by default) along the top and left edges. You can drag guides from these rulers onto the canvas to help with alignment.

Layers Dialog (Right Panel)

The Layers dialog is typically docked in the upper-right area. It shows the layer stack — a list of all layers in your image from top to bottom. The top layer in the list is drawn on top of all others, just like stacking transparent sheets of paper.

From the Layers dialog, you can:

  • Create, duplicate, and delete layers
  • Reorder layers by dragging them up or down
  • Toggle layer visibility with the eye icon
  • Adjust layer opacity with the slider
  • Change the layer blend mode (Normal, Multiply, Screen, Overlay, etc.)

Colors Dialog

The Colors dialog (often docked as a tab near the Layers dialog) lets you select your foreground and background colors. You can choose colors using a color wheel, sliders (HSV, RGB), a color palette, or by entering a hex code directly.

Brushes, Patterns, and Gradients

Additional dockable dialogs let you browse and select:

  • Brushes — choose from dozens of built-in brush tips or load custom ones
  • Patterns — tileable textures you can use with the Bucket Fill or Clone tool
  • Gradients — smooth color transitions used with the Gradient tool

Customizing the Layout

GIMP's interface is highly customizable. You can rearrange the workspace to suit your preferences:

  • Rearrange dockable dialogs — click and drag dialog tabs to move them between docks or create new docks.
  • Add dialogs — go to Windows > Dockable Dialogs to open any panel you need (Histogram, Undo History, Navigation, Fonts, etc.).
  • Remove dialogs — close any tab you don't use to reduce clutter.
  • Save your layout — GIMP automatically saves your window arrangement when you quit (if the option is enabled in Preferences).
Tip: If you ever completely mess up your layout, you can reset it by going to Edit > Preferences > Window Management and clicking Reset Saved Window Positions to Default Values, then restarting GIMP.

Summary

  • Use Single-Window Mode for a clean, organized workspace.
  • The Toolbox holds all tools; Tool Options shows settings for the active tool.
  • The Canvas is your editing area; the Layers dialog manages the layer stack.
  • The menu bar gives access to every feature — explore each menu to learn what's available.
  • Customize your layout with dockable dialogs and panel arrangements.

Selection Tools

Isolating Parts of Your Image for Editing

What Are Selections?

A selection defines a specific area of your image that you want to work on. When a selection is active, any edits you make — painting, filling, filtering, deleting — will only affect the selected area. The boundary of a selection is shown as animated dashed lines, often called marching ants.

Mastering selection tools is fundamental to image editing. They let you isolate subjects, cut out objects, apply effects to specific regions, and create precise compositions.

Selection Tools Reference

Rectangle Select (R)

Draws a rectangular selection. Click and drag to define the rectangle. Hold Shift after you start dragging to constrain the selection to a perfect square. In Tool Options you can enable Fixed aspect ratio, fixed size, or rounded corners.

Ellipse Select (E)

Draws an elliptical (oval) selection. Click and drag to define the ellipse. Hold Shift after starting the drag to constrain to a perfect circle. Works similarly to the Rectangle Select with the same Tool Options.

Free Select / Lasso (F)

Lets you draw a freehand selection by clicking and dragging, or click point-by-point to create a polygonal selection. Press Enter or double-click to close the selection. This tool is useful for irregular shapes that don't fit neatly into rectangles or ellipses.

Fuzzy Select / Magic Wand (U)

Selects a contiguous region of similar colors. Click on a pixel, and GIMP will select all connected pixels that are similar in color. The Threshold setting in Tool Options controls how similar a color must be to be included — a low threshold selects only very similar colors, while a high threshold selects a broader range.

Tip: The Fuzzy Select tool works best on images with solid or clearly defined color areas. For photos with subtle color gradients, try Select by Color instead.

Select by Color (Shift+O)

Similar to Fuzzy Select, but it selects all pixels of a similar color across the entire image — not just the ones connected to where you clicked. This is great for selecting all instances of a background color, even if they're separated by other objects.

Selection Modifiers

You can combine selections to build complex shapes. These modifiers work with any selection tool:

Modifier Key Effect
Replace (default) Replaces any existing selection with the new one.
Add Shift Adds the new selection area to the existing selection.
Subtract Ctrl Removes the new selection area from the existing selection.
Intersect Shift+Ctrl Keeps only the area where the old and new selections overlap.

Feathering

Feathering softens the edges of a selection by gradually fading it out over a specified number of pixels. Instead of a hard, sharp boundary, a feathered selection creates a smooth transition. This is useful for blending composited elements so they don't look like they were cut out with scissors.

You can enable feathering in the Tool Options before making a selection, or apply it afterward with Select > Feather.

Select Menu Commands

The Select menu provides additional powerful operations:

Command Shortcut Description
Select All Ctrl+A Selects the entire canvas.
Select None Ctrl+Shift+A Removes all selections (deselects everything).
Invert Selection Ctrl+I Selects everything that was not selected, and deselects what was.
Grow — Expands the selection boundary outward by a specified number of pixels.
Shrink — Contracts the selection boundary inward.
Border — Converts the selection into a border (ring) of a specified width.

Quick Mask Mode

Quick Mask is an advanced selection method that lets you paint your selection instead of drawing it with selection tools. To toggle Quick Mask mode, press Shift+Q or click the small square at the bottom-left corner of the canvas.

When Quick Mask is active, the canvas shows a red overlay on unselected areas. You can then use any paint tool:

  • Paint with black to remove from the selection (adds red overlay)
  • Paint with white to add to the selection (removes red overlay)
  • Paint with gray to create a partially selected (feathered) area

When you're done painting, press Shift+Q again to convert the mask back into a standard marching-ants selection.

Tip: Quick Mask is excellent for making detailed selections around hair, fur, or other complex edges where standard selection tools struggle.

Summary

  • Use Rectangle and Ellipse Select for geometric selections.
  • Use Free Select for irregular hand-drawn selections.
  • Use Fuzzy Select and Select by Color for color-based selections.
  • Combine selections with Shift (add), Ctrl (subtract), and Shift+Ctrl (intersect).
  • Use Feathering for soft-edged selections.
  • Use Quick Mask to paint precise selections with a brush.

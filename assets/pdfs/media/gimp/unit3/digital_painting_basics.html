Digital Painting Basics

Painting Original Artwork in GIMP

Overview

Digital painting is the process of creating artwork from scratch on a computer using tools that simulate traditional brushes, pencils, and paint. GIMP provides everything you need to paint digitally — customizable brushes, pressure sensitivity with drawing tablets, and a layer-based workflow that gives you far more flexibility than physical media.

Brush Tool Settings

The Paintbrush (P) is your primary painting tool. Understanding its settings is key to getting the results you want.

Brush Tip

The brush tip defines the shape and texture of each stroke. GIMP comes with dozens of built-in brush tips — round, square, textured, soft, and hard. Select a brush tip from the Brushes dialog or from the brush selector in Tool Options.

Size

Controls the diameter of the brush. Use [ and ] to quickly decrease or increase the size. Large brushes are great for blocking in color; small brushes are for fine details.

Opacity

Controls how transparent each stroke is. At 100%, the stroke is fully opaque; at lower values, underlying content shows through. Building up low-opacity strokes creates smooth, gradual transitions — a fundamental painting technique.

Dynamics

Paint dynamics link brush properties to input from a drawing tablet or mouse. When using a pressure-sensitive tablet, dynamics can map pen pressure to:

  • Size — press harder for a wider stroke, lighter for a thinner one.
  • Opacity — press harder for more opaque paint, lighter for more transparent.
  • Color — vary the color based on pressure (e.g., from foreground to background color).
  • Hardness — press harder for sharp edges, lighter for soft edges.

GIMP includes several preset dynamics profiles. Select one from the Dynamics dropdown in Tool Options. "Basic Dynamics" is a good starting point — it maps pressure to size and opacity.

Tip: If you're using a mouse instead of a tablet, dynamics won't respond to pressure, but you can still use dynamics mapped to velocity (speed of the stroke) or random variation for texture effects.

Spacing

Controls the distance between each dab (stamp) of the brush as you draw a stroke. Lower spacing creates a smooth, continuous line; higher spacing creates a dotted or textured effect. For painting, keep spacing low (around 10–20%).

Jitter

Adds random positional variation to each brush dab, scattering them around the stroke path. This creates natural, organic textures. Use low jitter for controlled painting and higher jitter for effects like foliage, grass, or particle textures.

Custom Brushes

You can create your own brush tips from any image:

  1. Create or open a small image (ideally square, grayscale). Dark areas will be opaque; white areas will be transparent.
  2. Go to File > Export As and save it as a .gbr file (GIMP Brush) in GIMP's brushes folder.
  3. Click Refresh in the Brushes dialog to load the new brush.

Custom brushes are great for stamps, textures, and specialized effects like leaves, clouds, or fur.

Digital Painting Workflow

A structured layer-based workflow keeps your painting organized and flexible:

Step 1: Rough Sketch

Create a new layer and name it "Sketch." Using a small, hard brush (the Pencil tool or a hard-edged Paintbrush), draw the rough outlines and composition of your subject. Lower the layer's opacity to around 20–30% so the sketch acts as a faint guide.

Step 2: Base Colors

Create a new layer below the sketch and name it "Base Colors." Using a larger brush, block in the main color areas of your painting. Don't worry about shading or detail yet — just lay down flat, solid colors to establish the palette. This is sometimes called "flatting."

Step 3: Shading

Create a new layer above the base colors and name it "Shading." Using darker versions of your base colors (or using the Multiply blend mode on this layer), paint in shadows. Consider where the light source is: areas facing away from the light should be darker. Use a soft brush at reduced opacity to build up shadows gradually.

Step 4: Highlights and Details

Create another new layer on top named "Details." Add highlights (bright spots where light hits directly), texture details, small features (eyes, patterns, edges), and any finishing touches. Use a smaller brush and zoom in closely.

Tip: You can always add more layers for specific elements — rim lighting, background effects, color overlays. More layers means more control, but don't overthink it early on.

Color Theory Basics

Understanding color will dramatically improve your paintings:

Complementary Colors

Colors that sit opposite each other on the color wheel (red and green, blue and orange, yellow and purple). Placing complementary colors next to each other creates vibrant contrast and makes both colors appear more intense.

Warm and Cool Colors

Warm colors (reds, oranges, yellows) feel energetic and advance forward visually. Cool colors (blues, greens, purples) feel calm and recede into the background. Use this to create depth — warm your foreground, cool your background.

Value

Value refers to how light or dark a color is. A painting with a good range of values — from deep darks to bright highlights — will look three-dimensional and readable even in grayscale. If your painting looks flat, the problem is almost always insufficient value contrast.

Using Reference Images

Even professional artists use references. Keep reference images open alongside your canvas:

  • Photos for anatomy, lighting, texture, and proportion
  • Color palette references for consistent, harmonious color choices
  • Artwork by other artists for inspiration and technique study

Using references is not cheating — it's good practice. The goal is to learn from reality and other art, not to copy them exactly.

Summary

  • Configure brush size, opacity, dynamics, spacing, and jitter for different effects.
  • Use paint dynamics with a tablet for pressure-sensitive strokes.
  • Create custom brushes from images for unique textures and stamps.
  • Follow a layered workflow: sketch → base colors → shading → details.
  • Apply color theory: complementary colors, warm/cool, and value contrast.
  • Use reference images to improve accuracy and learn from reality.

Paths & Vectors

Drawing Precise Shapes with Bézier Curves

What Are Paths?

A path (also called a vector path) is a line defined by mathematical points rather than pixels. Unlike painted strokes, paths are infinitely smooth at any zoom level and can be edited, reshaped, and reused at any time without quality loss. Paths are not visible in the final image — they are guides that you convert into selections, strokes, or text curves.

The Paths Tool

Select the Paths tool by pressing B or clicking its icon in the Toolbox (it looks like a fountain pen nib). The Paths tool creates Bézier curves — smooth curves defined by anchor points and control handles.

Creating Paths

  • Click to place a corner anchor point (a straight segment connects each point).
  • Click and drag to place a smooth anchor point with control handles. The handles determine the curve's direction and intensity — the further you drag, the more pronounced the curve.
  • Continue clicking or click-dragging to add more points.
  • To close the path (create a shape), hold Ctrl and click on the first point.
  • Press Enter to confirm the path.
Tip: When drawing curves, fewer points usually produce smoother results. Try to use as few anchor points as possible and let the control handles do the shaping.

Editing Path Nodes

After creating a path, you can refine it by editing its anchor points (nodes):

  • Move a node — click and drag any anchor point to reposition it.
  • Adjust handles — click and drag a control handle to change the curve shape.
  • Add a node — click on a path segment between two existing nodes. A new anchor point appears.
  • Delete a node — hold Ctrl+Shift and click a node to remove it.

The Paths dialog (accessible from Windows > Dockable Dialogs > Paths) shows all paths in the current image. You can have multiple paths, rename them, toggle their visibility, and select which path is active.

Path to Selection

One of the most important uses of paths is converting them into pixel-perfect selections:

  • Press Enter while the path is active, or
  • Go to Select > From Path.

The path becomes a marching-ants selection. You can then fill, paint, delete, or apply effects inside the selected area. This technique is ideal for cutting out objects with smooth, precise edges.

Selection to Path

You can also do the reverse — convert any existing selection into a path:

  • Go to Select > To Path.

This creates an editable path from the selection boundary, letting you refine the shape with the Paths tool before converting back to a selection.

Stroking a Path

Stroking a path means drawing a visible line along the path. Go to Edit > Stroke Path and choose:

  • Stroke line — draws a line of a specified width, with options for line style (solid, dashed, dotted), cap style, and join style.
  • Stroke with a paint tool — uses the currently selected brush and paint tool to draw along the path. This lets you create strokes with textures, opacity variation, and dynamics.

Stroking is how you turn an invisible path into visible artwork — outlines, borders, decorative lines, and custom shapes.

Tip: Before stroking, make sure you're on the correct layer and that the foreground color and brush settings are what you want. The stroke will be painted onto the active layer.

Common Uses for Paths

  • Precise cutouts — use paths to trace around objects for clean selections, especially when other selection tools struggle with complex edges.
  • Custom shapes — draw stars, arrows, logos, and other geometric or freeform shapes with smooth, scalable curves.
  • Text along a curve — create a curved path and use Layer > Text along Path to flow text along it (covered in the Text & Typography lesson).
  • Decorative borders and lines — stroke paths with custom brushes for artistic outlines.

Summary

  • The Paths tool (B) creates Bézier curves with anchor points and control handles.
  • Click for straight corners; click and drag for smooth curves.
  • Edit nodes by moving, adding, or deleting anchor points.
  • Convert paths to selections with Select > From Path (Enter).
  • Convert selections to paths with Select > To Path.
  • Stroke Path (Edit > Stroke Path) draws a visible line along the path.

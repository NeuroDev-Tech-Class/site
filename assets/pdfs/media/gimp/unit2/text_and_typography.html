Text & Typography

Adding and Styling Text in GIMP

The Text Tool

The Text tool (T) lets you add text to your image. Click anywhere on the canvas to place a text cursor, then start typing. A floating text editor may appear for longer text. The text is placed on its own special text layer, which you can see in the Layers dialog marked with a "T" icon.

Text Tool Options

When the Text tool is active, the Tool Options panel (below the Toolbox) provides all the typography controls you need:

Setting Description
Font Choose from all fonts installed on your system. Click the font name to browse or type to search.
Size Font size in pixels (px), points (pt), or other units. For screen use, px is most common.
Color The text color. Click the color swatch to open the color chooser. By default, text uses the current foreground color.
Justify Text alignment — left, center, right, or fill (justified on both sides).
Letter Spacing Adjusts the space between individual characters (tracking). Increase for an airy, spaced-out look; decrease for tighter text.
Line Spacing Adjusts the vertical space between lines of text (leading). Increase for readability in body text.
Tip: You can change any of these settings after placing the text. Just select the Text tool, click on the text layer on the canvas, select the text you want to change, and adjust the options.

Working with Text Layers

Text layers are special in GIMP — they remain editable as long as they stay as text layers. You can go back and change the wording, font, or size at any time by clicking on them with the Text tool.

However, text layers have limitations: you cannot paint on them, apply most filters to them, or use many pixel-level tools. To unlock the full range of editing capabilities, you must first flatten the text layer to a regular image layer.

Flattening a Text Layer

To convert a text layer into a normal pixel layer, go to Layer > Discard Text Information or right-click the text layer in the Layers dialog and choose the same option. After flattening, the text is no longer editable as text — it becomes ordinary pixels that you can paint on, filter, transform, and manipulate freely.

Warning: Once you flatten a text layer, you cannot go back and edit the text. Always make sure your text is final (correct spelling, right font, right size) before flattening.

Text Along a Path

One of GIMP's most powerful text features is the ability to flow text along a curved path. This is perfect for circular text, wavy text, or text that follows any custom shape.

  1. Create a path using the Paths tool (B). Draw the curve you want the text to follow.
  2. Type your text using the Text tool. The wording, font, and size should be set now.
  3. Make sure the text layer is active in the Layers dialog.
  4. Go to Layer > Text along Path. GIMP will create a new path in the Paths dialog that follows your original path's curve in the shape of the text characters.
  5. Go to Edit > Stroke Path or use Select > From Path and then fill the selection to render the text along the curve.
Tip: Make the path longer than you think you'll need. If the path is too short, text characters will bunch up or be cut off at the end.

Adding Effects to Text

Once you flatten a text layer (or use Alpha to Selection), you can apply any visual effect. Here are some popular text effects:

Drop Shadow

  1. Right-click the text layer and choose Alpha to Selection (selects the shape of the text).
  2. Go to Filters > Light and Shadow > Drop Shadow.
  3. Adjust offset, blur, color, and opacity.

Gradient Fill Text

  1. Right-click the text layer and choose Alpha to Selection.
  2. Create a new layer above the text layer.
  3. Select the Gradient tool (G), choose your gradient colors, and drag across the selection.
  4. The gradient will fill only the text shape.

Bevel / Emboss and Logo Effects

GIMP includes built-in logo scripts that can create elaborate text effects automatically:

  1. Go to Filters > Alpha to Logo.
  2. Browse the available effects: 3D Outline, Alien Glow, Basic I & II, Blended, Chrome, Cool Metal, Glossy, Neon, and many more.
  3. Select an effect and configure its settings.

These scripts generate multiple layers with lighting, shadows, and color effects to create polished, professional-looking text treatments.

Typography Best Practices

  • Limit your fonts — use no more than 2–3 different fonts in a single design.
  • Use font hierarchy — make titles large and bold, subtitles medium, and body text smaller.
  • Ensure contrast — text should be easy to read against the background. Light text on dark backgrounds (or vice versa).
  • Watch spacing — adjust letter spacing and line spacing for readability.
  • Avoid stretching text — use the Scale tool on text sparingly. Distorted text looks unprofessional. Change the font size instead.

Summary

  • Use the Text tool (T) to place editable text on its own layer.
  • Control font, size, color, alignment, and spacing in Tool Options.
  • Flatten text to a pixel layer before applying filters or painting on it.
  • Use Text along Path for curved or shaped text.
  • Apply effects like drop shadows, gradients, and logo scripts using Alpha to Selection.

Audio Production — Audacity

Importing & Exporting Audio

Bring audio into your project and save it in the right format for any purpose

Opening vs. Importing

There are two different ways to bring an audio file into Audacity, and they behave differently:

MethodWhat Happens
File > OpenOpens the audio file in a brand-new Audacity project window. Use this when you want to work on a single file by itself.
File > Import > AudioAdds the audio file to your current project as a new track. Use this when you want to combine multiple audio files (e.g., voice + music).

Importing Multiple Files

You can import several files at once:

  1. Go to File > Import > Audio.
  2. In the file browser, hold Ctrl and click to select multiple files (or hold Shift to select a range).
  3. Click Open.
  4. Each file appears as its own track in the project.

Drag and Drop

You can also drag audio files directly from your file explorer into the Audacity window. Each dragged file is imported as a new track in the current project — the same behavior as File > Import > Audio.

Tip: Audacity can import WAV, MP3, OGG, FLAC, and many other formats. If a format isn't supported, you may need to install the FFmpeg library (Audacity will prompt you with instructions).

Exporting Audio

When your project is finished, you need to export it as a standard audio file that any media player can open. This is different from saving the project (more on that below).

  1. Go to File > Export Audio (or press Ctrl+Shift+E).
  2. Choose a file name and location.
  3. Select the format from the dropdown.
  4. Configure format-specific settings (e.g., bitrate for MP3).
  5. Click Export.
  6. A Metadata dialog may appear — fill in tags or click OK to skip.

Export Formats

WAV (Waveform Audio File)

  • Type: Uncompressed
  • Quality: Full quality — no data is lost.
  • File size: Large (about 10 MB per minute of stereo audio at 44.1 kHz / 16-bit).
  • Best for: Editing, archiving, and when quality matters most.

MP3 (MPEG Audio Layer III)

  • Type: Lossy compressed
  • Quality: Good to excellent, depending on bitrate. Some audio data is permanently removed.
  • File size: Small (about 1 MB per minute at 128 kbps).
  • Bitrate options:
    • 128 kbps — Acceptable for spoken word and casual listening.
    • 192 kbps — Good balance of quality and size. Recommended for podcasts.
    • 256 kbps — High quality for music sharing.
    • 320 kbps — Highest MP3 quality. Nearly indistinguishable from the original.
  • Best for: Sharing online, uploading to websites, distributing to listeners.

OGG Vorbis

  • Type: Lossy compressed (open-source)
  • Quality: Similar to or slightly better than MP3 at the same bitrate.
  • File size: Small, comparable to MP3.
  • Best for: Open-source projects, game audio, situations where patent-free formats are preferred.

FLAC (Free Lossless Audio Codec)

  • Type: Lossless compressed
  • Quality: Perfect — identical to the original. No data is lost.
  • File size: Moderate (about 50–70% the size of WAV).
  • Best for: Archiving when you want smaller files without losing quality.
Tip: A good workflow is: save your project as an Audacity project (.aup3) for editing, export a WAV for archiving, and export an MP3 for sharing.

Export Selected Audio

Sometimes you only want to export a portion of your project. To do this:

  1. Use the Selection tool to highlight the region you want to export.
  2. Go to File > Export Audio.
  3. In the export dialog, look for the option "Current Selection" (or use File > Export Selected Audio in older versions).
  4. Choose your format and click Export.

Only the selected audio will be written to the file.

Metadata Tags

When exporting, Audacity may show a Metadata Tags dialog. These tags are embedded in the audio file and provide information about the content:

  • Title — The name of the recording or track.
  • Artist — Who created the recording.
  • Album — The album or project name.
  • Track Number — Useful for multi-episode podcasts.
  • Year — The year of creation.
  • Genre — The category (Podcast, Music, Speech, etc.).
  • Comments — Any additional notes.

Media players (like Windows Media Player, VLC, or Spotify) display these tags. Filling them in keeps your files organized and professional.

Saving Projects vs. Exporting Audio

This is a critical distinction that trips up many beginners:

ActionWhat It Does
File > Save Project (Ctrl+S)Saves an .aup3 file — Audacity's project format. This preserves all tracks, edits, undo history, and effects settings. Only Audacity can open this file.
File > Export AudioCreates a standard audio file (WAV, MP3, etc.) that any media player can open. All tracks are mixed down to a single stereo (or mono) file.
Warning: Saving a project (Ctrl+S) does not create an audio file you can share or play in other apps. You must Export to create a playable audio file. Always do both: save the project for future editing and export the final audio.

Key Takeaways

  • File > Open opens in a new project; File > Import > Audio adds to the current project.
  • Export with File > Export Audio — choose WAV for quality/archiving, MP3 for sharing.
  • Fill in metadata tags to keep your files organized.
  • Save Project (.aup3) preserves your editable work; Export creates a shareable audio file. Do both.

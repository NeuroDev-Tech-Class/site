Activity: Model & Print a Ring

Design, Model, Slice, and 3D Print a Custom Ring

Overview

In this guided activity, you'll go through the entire pipeline from idea to physical object: research a ring size, model a custom ring in Blender, prepare it for printing, and produce a finished 3D-printed ring. This brings together modeling skills, modifier knowledge, and 3D printing fundamentals.

Step 1: Research Ring Sizes

Before you start modeling, you need to know the inner diameter of the ring so it fits the intended finger. There are two easy ways to figure this out:

  • Measure an existing ring: If you have a ring that fits, measure its inner diameter with a ruler or calipers. A US size 7 ring is about 17.3mm inner diameter.
  • Use a sizing chart: Look up a ring size chart online. Common sizes range from about 14mm (size 3) to 23mm (size 13) inner diameter.

Write down your target inner diameter in millimeters — you'll need this when creating the torus.

Step 2: Create a Torus in Blender

  1. Open Blender and delete the default cube (select it, press X, confirm).
  2. Add a torus: Add → Mesh → Torus (or press Shift+A and navigate to Mesh → Torus).
  3. Immediately after adding, look at the operator panel in the bottom-left corner. Here you can set the torus dimensions:
    • Major Radius: The distance from the center of the torus to the center of the tube. This determines the ring's overall size. Set this to half your inner diameter plus half the tube thickness.
    • Minor Radius: The thickness of the ring band itself. Start with something like 1.5-2.5mm for a realistic ring band.
    • Major Segments: Controls how round the ring is (48 is a good, smooth value).
    • Minor Segments: Controls how round the band cross-section is (12-16 works well).
  4. After setting values, click away to confirm. Note: You can only adjust these settings right after adding the torus — once you perform another action, the operator panel disappears.

Step 3: Add Detail

Now make the ring your own! Here are some ideas:

  • Gemstone mount: Add a small sphere or cone on top of the ring to simulate a gem setting. Use a Boolean modifier to embed it into the band.
  • Engravings: Use the Knife tool or Boolean operations with text objects to carve initials, symbols, or patterns into the band.
  • Custom shape: Enter Edit Mode and reshape the band — make it wider at the top, add a flat face for a signet-style ring, or create a tapered design.
  • Pattern: Use the Array modifier to create repeating elements around the ring, like small bumps or facets.

Step 4: Use Modifiers

  • Bevel Modifier: Add a subtle bevel to the edges of the ring for a comfortable, rounded feel. Even 1-2 segments with a small width makes a difference — especially on the inner edge that touches your finger.
  • Subdivision Surface: If your ring has a faceted or angular look, a level-1 or level-2 Subdivision Surface smooths it out beautifully.
  • Boolean Modifier: Use this to cut shapes into the ring (like holes for a pattern) or to embed decorative elements. Remember that Booleans can create messy topology — clean up with the Knife tool and Merge if needed.

Step 5: Check for Manifold / Watertight Mesh

For a successful 3D print, your mesh must be manifold (also called "watertight") — meaning it forms a completely closed solid with no holes, gaps, or flipped faces. Imagine filling it with water: if water would leak out, the mesh isn't manifold.

  1. Enable the 3D Print Toolbox addon: Edit → Preferences → Add-ons → search "3D Print Toolbox" → enable it.
  2. In the 3D viewport sidebar (press N), find the 3D-Print tab.
  3. Click Check All to scan your mesh for problems.
  4. Fix any issues it reports: non-manifold edges, flipped normals, zero-area faces, etc.

Step 6: Export as STL

  1. Select your ring object.
  2. Go to File → Export → STL (.stl).
  3. In the export options, make sure Selection Only is checked (so you don't export other objects in the scene).
  4. Verify the Scale is set to 1.0 (assuming you modeled in millimeters). If you modeled at a different scale, adjust here.
  5. Choose a filename and location, then click Export STL.

Step 7: Load in Slicer, Orient, and Scale

  1. Open your slicer (Cura, PrusaSlicer, Bambu Studio, etc.).
  2. Import / drag in your STL file.
  3. Check the dimensions — do they match your intended ring size? Adjust the scale if needed.
  4. Orient the ring standing upright (like it's sitting on a finger) for best print quality. This minimizes the need for supports inside the ring hole.
  5. Add a brim for bed adhesion, since the ring has a small contact area with the bed.

Step 8: Print at Fine Layer Height

  • Set the layer height to 0.12mm for a smooth surface with minimal visible layer lines.
  • Preview the sliced layers to make sure everything looks correct.
  • Send the file to the printer and begin printing.
  • Once complete, carefully remove the ring from the build plate and peel off any brim material.
  • Try it on! If the fit is off, adjust your model dimensions and print again.

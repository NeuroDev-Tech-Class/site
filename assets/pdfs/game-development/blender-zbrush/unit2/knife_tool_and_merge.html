Knife Tool & Merge

Cutting, Merging, and Cleaning Up Geometry

The Knife Tool (K)

The Knife tool lets you manually cut new edges into existing faces. This is one of the most useful tools for fixing topology — you can split N-gons into quads, add edge loops where you need more detail, or carve custom shapes into a surface.

How to Use the Knife Tool

  1. Enter Edit Mode (Tab key).
  2. Press K to activate the Knife tool. Your cursor changes to a small knife icon.
  3. Click on the mesh to place a starting point for your cut. Each click adds a new point along the cut path.
  4. Continue clicking to draw the cut line across one or more faces. You'll see a green line showing the planned cut.
  5. Press Enter (or Return) to confirm the cut. New edges and vertices are created along your path.
  6. Press Escape to cancel if you change your mind.

Tips for the Knife Tool

  • Snap to midpoints: Hold Ctrl while using the knife to snap your cuts to the midpoint of edges. This helps keep geometry even.
  • Cut through: Press Z while the knife is active to cut through the entire mesh (front and back faces), not just the visible side. This is great for symmetrical cuts.
  • Stay on edges: Try to start and end your cuts on existing edges or vertices. Cuts that start or end in the middle of a face can create awkward geometry.
  • Fixing N-gons: If you have a 5-sided face, one knife cut from one edge to the opposite side can split it into a quad and a triangle — or two quads if you plan carefully.

Cutting Through Multiple Faces

The Knife tool isn't limited to a single face. You can draw a cut line across several faces in one operation. This is useful when you need to add a continuous edge loop manually, or when you want to carve a line across a complex surface. Just keep clicking across face boundaries — the knife will automatically split each face it crosses.

Merging Vertices (M)

Sometimes you end up with extra vertices that need to be combined into one. The Merge command does exactly this — it takes two or more selected vertices and collapses them into a single vertex.

How to Merge

  1. In Edit Mode, select two or more vertices you want to merge.
  2. Press M to open the Merge menu.
  3. Choose one of the following options:

Merge Options

  • At Center: All selected vertices collapse to the average center point between them. This is the most common option.
  • At Cursor: All selected vertices move to the 3D cursor's current position and merge there. Useful when you want precise control over where the merged vertex ends up.
  • Collapse: Each connected group of selected vertices merges at its own center. Useful when merging multiple pairs at once.
  • By Distance: Automatically merges any vertices that are closer together than a specified threshold. This is extremely useful for cleaning up overlapping vertices after a Boolean operation or import. You can adjust the merge distance in the operator panel (bottom-left corner) after running it.

When to Use Merge

  • Closing gaps where two edges almost meet but aren't connected.
  • Cleaning up doubled vertices (two vertices sitting in the exact same spot).
  • Simplifying geometry by collapsing unnecessary detail.
  • Joining separate mesh pieces into a continuous surface.

Dissolve vs. Delete

When you want to remove geometry, Blender offers two different approaches: Delete and Dissolve. Understanding the difference is important.

Delete (X or Delete Key)

Pressing X or Delete opens the Delete menu. Deleting a vertex, edge, or face removes it entirely, leaving a hole in the mesh. For example, deleting a face removes that face and leaves an open gap where it used to be. This is useful when you intentionally want to create an opening or remove unwanted parts of a mesh.

Dissolve (Ctrl + X)

Dissolve removes edges or vertices without leaving a hole. Instead, the surrounding faces merge together to fill the space. For example, dissolving an edge between two quads combines them into one larger face. Dissolving is the tool of choice when you want to simplify topology without creating gaps.

  • Dissolve Vertices: Removes a vertex and merges the surrounding edges and faces.
  • Dissolve Edges: Removes an edge and merges the two faces on either side into one.
  • Dissolve Faces: Merges selected faces into a single face (may create an N-gon).

When to Use Each

Situation Use
Remove a face and leave a hole Delete (X)
Remove an edge loop to simplify topology Dissolve (Ctrl+X)
Get rid of an extra vertex on an edge Dissolve Vertices
Delete an entire section of a mesh Delete (X)
Merge two adjacent faces into one Dissolve Edges

Putting It All Together

These three skills — cutting with the Knife tool, merging vertices, and dissolving/deleting — form your core toolkit for cleaning up mesh topology. A typical workflow might look like this:

  1. Identify an N-gon using Select → All by Trait → Faces by Sides.
  2. Use the Knife tool (K) to cut it into quads.
  3. If the cut created any overlapping vertices, Merge by Distance (M) to clean them up.
  4. If you accidentally created unnecessary edges, Dissolve (Ctrl+X) to remove them without leaving holes.

Practice these tools often — they're essential for every 3D modeler, from beginner to professional.

Navigation & Transforms

Moving through 3D space and manipulating objects

Navigating the Viewport

Before you can model anything, you need to be comfortable moving around the 3D viewport. Blender's navigation relies heavily on the mouse — especially the middle mouse button (MMB). If you have a mouse with a scroll wheel that clicks, you're all set.

Basic Navigation Controls

  • Zoom: Scroll the Mouse Wheel up to zoom in, down to zoom out
  • Orbit: Click and drag with MMB (middle mouse button) to rotate the view around the scene
  • Pan: Hold Shift + click and drag with MMB to slide the view left, right, up, or down without rotating
No middle mouse button? Go to Edit > Preferences > Input and check "Emulate 3 Button Mouse." This lets you use Alt+Left Click instead of MMB.

Numpad Views

The numpad gives you instant access to precise, aligned views. These are incredibly useful when you need to see your model from an exact angle:

  • Numpad 1 — Front view (looking down the Y axis)
  • Numpad 3 — Right side view (looking down the X axis)
  • Numpad 7 — Top view (looking down the Z axis)
  • Numpad 5 — Toggle between Perspective and Orthographic view
  • Numpad 0 — Camera view (what the camera sees for rendering)

Holding Ctrl with a numpad key gives you the opposite view. For example, Ctrl+Numpad 1 gives you the Back view.

Perspective vs. Orthographic: Perspective view mimics how your eyes see the world — objects farther away look smaller. Orthographic view has no depth distortion — useful for precise alignment. Toggle with Numpad 5.

The Navigation Gizmo

In the top-right corner of the viewport, you'll see a small set of colored axes (the navigation gizmo). You can click on any axis letter (X, Y, or Z) to snap to that view. You can also click and drag the gizmo to orbit the scene. This is a helpful visual alternative to using the MMB.

Selecting Objects

Before you can transform an object, you need to select it. In Blender:

  • Left-click an object to select it (it gets an orange outline)
  • Shift+Left-click to add more objects to the selection
  • Click on empty space to deselect everything
  • A — Select all objects
  • Alt+A — Deselect all

Transforms: Move, Rotate, Scale

Transforms are the three fundamental operations you'll use constantly. Each one has a single-key shortcut:

Grab / Move — G

Select an object and press G to grab it. Move your mouse to reposition the object, then left-click to confirm or right-click (or Esc) to cancel.

Rotate — R

Select an object and press R to rotate it. Move your mouse to spin the object, then left-click to confirm.

Scale — S

Select an object and press S to scale (resize) it. Move your mouse outward to enlarge or inward to shrink, then left-click to confirm.

Axis Locking

After pressing G, R, or S, you can press X, Y, or Z to lock the transform to a single axis. This is extremely useful for precise control:

  • G then Z — Move the object only up and down
  • R then X — Rotate only around the X axis
  • S then Y — Scale only along the Y axis

Precise Input

After pressing a transform shortcut and (optionally) an axis key, you can type a number to set an exact value:

  • G → Z → type 3 → Enter — Moves the object up exactly 3 units
  • R → X → type 90 → Enter — Rotates 90° around the X axis
  • S → type 2 → Enter — Doubles the object's size
  • S → type 0.5 → Enter — Shrinks the object to half its size

Adding and Deleting Objects

Adding Objects — Shift+A

Press Shift+A to open the Add menu. From here you can insert new objects into the scene:

  • Mesh — Cube, Sphere, Cylinder, Plane, Cone, Torus, and more
  • Light — Point, Sun, Spot, Area
  • Camera — Additional cameras
  • Empty — Invisible reference objects (advanced)

Objects are added at the position of the 3D cursor (the small crosshair in the scene). If you want to reset the 3D cursor to the center, press Shift+C.

Deleting Objects

Select the object you want to remove and press the Delete key (or X). A confirmation popup will appear — click Delete to confirm.

Shortcut Reference Popup

Press Shift+Space to open a quick tool shortcut popup that lists available tools and their shortcuts. This is a handy reference while you're still memorizing keys.

Edit Mode & Mesh Elements

Understanding vertices, edges, faces, and how meshes work

Entering Edit Mode

In the previous lessons, we worked in Object Mode, where we can select and transform entire objects. To shape the actual geometry of an object — to move individual points, reshape edges, and delete or add faces — we need to switch to Edit Mode.

To enter Edit Mode:

  1. Select the object you want to edit (left-click it so it has an orange outline)
  2. Press Tab

The object will change appearance — you'll see its wireframe structure overlaid on the surface, and the mode indicator at the top-left of the viewport will switch from "Object Mode" to "Edit Mode."

Press Tab again to return to Object Mode. You'll go back and forth between these two modes constantly while modeling.

Remember: You must have an object selected before pressing Tab. Edit Mode works on one object at a time.

The Three Mesh Elements

Every 3D mesh is made up of three fundamental building blocks. Understanding these is the key to understanding 3D modeling:

Vertices (Points)

A vertex (plural: vertices) is a single point in 3D space. It has an X, Y, and Z position. By itself, a vertex is just a dot — it has no size or shape. But vertices are the foundation that everything else is built on.

A cube has 8 vertices — one at each corner.

Edges (Lines)

An edge is a straight line connecting two vertices. Edges define the outline and wireframe of your model. They have length but no surface area.

A cube has 12 edges — the lines you see along every side of the cube.

Faces (Surfaces)

A face is a flat surface enclosed by three or more edges. Faces are what you actually see when you look at a 3D model — they catch light, display colors and textures, and make the object look solid.

A cube has 6 faces — one for each side (top, bottom, front, back, left, right).

Think of it like this: Vertices are dots. Connect two dots and you get an edge (a line). Connect three or more edges in a loop and you get a face (a surface). A 3D mesh is just a collection of connected vertices, edges, and faces.

Selection Modes

Once you're in Edit Mode, you need to choose which type of element you want to select and manipulate. There are three selection modes, toggled with the number keys (not numpad):

  • 1 — Vertex select mode — click to select individual vertices
  • 2 — Edge select mode — click to select individual edges
  • 3 — Face select mode — click to select individual faces

You can also switch modes by clicking the three icons in the header bar at the top of the viewport (they look like a dot, a line, and a square).

Selection Techniques

Being able to quickly select exactly what you need is a core modeling skill. Here are the most important selection methods:

Basic Selection

  • Left-click — Select a single element (deselects everything else)
  • Shift+Left-click — Add to selection (select multiple elements one by one)
  • Alt+A — Deselect all
  • A — Select all

Box Select — B

Press B, then click and drag to draw a rectangle. Everything inside the rectangle gets selected. This is great for selecting a group of nearby elements quickly.

Circle Select — C

Press C to enter circle select mode. A circle appears around your cursor — click and drag to "paint" a selection over elements. Scroll the mouse wheel to change the circle size. Press Esc or right-click to exit circle select mode.

Loop Select — Alt+Click

Hold Alt and click on an edge or face to select an entire loop — a ring of connected elements that goes all the way around the mesh. This is extremely useful and you'll use it all the time once you start adding loop cuts.

Select Linked — Ctrl+L

With at least one element selected, press Ctrl+L to select all elements that are connected to the current selection. This is handy when you have multiple separate meshes inside the same object and want to select just one of them.

How Meshes Are Built

When you model in Blender, you're essentially sculpting a mesh by adding, removing, and rearranging vertices, edges, and faces. All modeling tools in Blender operate on these three elements.

A well-constructed mesh uses primarily quads — faces made of exactly 4 vertices and 4 edges. Quads are preferred because they subdivide cleanly, deform well for animation, and produce predictable shading. Triangles (3-sided faces, called tris) are sometimes unavoidable, but too many triangles can cause shading artifacts. Faces with 5 or more sides (n-gons) should generally be avoided.

Beginner rule of thumb: Try to keep your faces as quads (4 sides). Don't worry about this too much right now — just be aware that quad-based meshes are cleaner and easier to work with.

Normals

Every face has a normal — an invisible arrow pointing outward from the face, perpendicular to its surface. Normals determine which direction a face "points." This matters because:

  • Faces are usually only visible from the side their normal points toward
  • Lighting calculations use normals to determine how bright or dark a face appears
  • Flipped normals (pointing inward instead of outward) can make faces appear invisible or shaded incorrectly

If parts of your model look dark, transparent, or inside-out, you might have flipped normals. To fix them:

  1. Enter Edit Mode
  2. Select all with A
  3. Go to Mesh > Normals > Recalculate Outside (or press Shift+N)

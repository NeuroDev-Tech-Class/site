Extrude, Inset & Loop Cut

The three most important modeling tools in Blender

Why These Three Tools?

Of all the tools in Blender's modeling toolkit, Extrude, Inset, and Loop Cut are the ones you'll reach for the most. Together, they let you add geometry, create detail, and shape almost any object imaginable — all starting from a simple cube. Master these three tools and you can model just about anything.

All three tools are used in Edit Mode. Make sure you've entered Edit Mode (Tab) before trying to use them.

Extrude — E

Extrude creates new geometry by pushing or pulling a selected face (or edge, or vertex) outward or inward from the mesh. It's like pulling fresh clay out of an existing surface.

How to Use Extrude

  1. Enter Edit Mode (Tab)
  2. Switch to Face select mode (3)
  3. Select one or more faces
  4. Press E
  5. Move the mouse to push the new geometry outward (or inward)
  6. Left-click to confirm, or right-click / Esc to cancel

Extrude Along an Axis

After pressing E, you can press X, Y, or Z to constrain the extrusion to a specific axis. By default, Extrude moves along the face's normal (the direction the face points), which is usually what you want.

Extrude Along Normals

If you have multiple faces selected, you can use Extrude Faces Along Normals to push each face outward along its own normal. Access this through Mesh > Extrude > Extrude Faces Along Normals, or press Alt+E to open the Extrude menu.

Common mistake: If you press E and then immediately right-click to cancel, the new geometry is still created — it's just sitting in the same spot as the original face. This creates double faces (overlapping geometry) which can cause shading problems. If you accidentally do this, immediately press Ctrl+Z to undo.

Extrude Inward

Extrude doesn't just go outward. Move the mouse inward (toward the object's center) to create an indentation or hole. This is great for creating recessed details like windows, buttons, or grooves.

Inset — I

Inset creates a smaller face inside an existing face. It doesn't add depth — it just divides the face into an inner face surrounded by a border of new faces. Think of it like creating a picture frame on the surface of your model.

How to Use Inset

  1. Enter Edit Mode and switch to Face select mode (3)
  2. Select one or more faces
  3. Press I
  4. Move the mouse to control how much the face is inset
  5. Left-click to confirm

Why Inset Is Useful

Inset is often used before an extrude. By insetting first, you create a smaller face that you can then extrude inward or outward. This pattern — Inset then Extrude — is one of the most common modeling workflows:

  • Inset + Extrude inward = a window or recessed panel
  • Inset + Extrude outward = a raised button or bump
  • Inset alone = decorative border detail
Tip: When you have multiple faces selected and press I, Blender insets them as a single region by default. If you want each face inset individually, press I twice (or press I then I again) to toggle Individual mode.

Loop Cut — Ctrl+R

Loop Cut adds a new ring of edges (a loop) around your mesh, dividing it into more sections. More sections means more geometry to work with, which means more detail and more control.

How to Use Loop Cut

  1. Enter Edit Mode (Tab)
  2. Press Ctrl+R
  3. Hover your mouse over an edge — a yellow preview line will appear showing where the cut will go
  4. Scroll the Mouse Wheel to add more parallel cuts
  5. Left-click to place the cut(s)
  6. Move the mouse to slide the cut along the surface, then left-click to confirm — or right-click to snap the cut to the exact center
Tip: Right-clicking during the slide step places the loop cut at the exact center between edges. This is usually what you want, so get in the habit of: Ctrl+R → hover → click → right-click.

Why Loop Cuts Matter

A default cube only has 6 faces — that's not much to work with. By adding loop cuts, you create many more faces that you can select, extrude, inset, move, and shape independently. Loop cuts are how you go from a blocky shape to a detailed model.

Combining the Three Tools

The real power comes from using these tools together. Here's the general workflow:

  1. Loop Cut to add more geometry where you need detail
  2. Inset faces to create smaller target areas
  3. Extrude those faces inward or outward to create 3D features

Almost every hard-surface model (furniture, vehicles, buildings, props) follows this pattern.

Step-by-Step Example: Model a Simple Table

Let's put all three tools together to model a basic table from the default cube.

Building a Table from a Cube

  1. Start with the default cube. Open Blender and leave the default cube in the scene. Enter Edit Mode (Tab).
  2. Scale it into a tabletop shape. Press S, then Z, then type 0.1 and press Enter. This flattens the cube along the Z axis. Now press S, then X, type 2, and press Enter to stretch it wider. You should have a flat slab shape.
  3. Add loop cuts for the legs. Press Ctrl+R and hover over a horizontal edge to see a vertical cut preview. Left-click to place it, then right-click to center it. Repeat on the other axis so you have a grid on the bottom face. You want at least 2 cuts in each direction so the bottom of the table has a 3×3 grid of faces.
  4. Select the four corner faces on the bottom. Switch to Face select mode (3). Look at the bottom of your table (press Numpad 7 for the top view, then Ctrl+Numpad 7 for the bottom view). Select the four corner faces by clicking one, then Shift+clicking the other three.
  5. Inset the corner faces. Press I, then I again (to toggle individual mode so each face insets separately). Move the mouse to create a small inset on each face, then left-click.
  6. Extrude the legs. With the four inset faces still selected, press E, then Z, then type -2 and press Enter. This extrudes four legs downward from the table.
  7. Exit Edit Mode. Press Tab to return to Object Mode and admire your table!

Congratulations — you've just used all three core modeling tools to create a real object from a single cube. The same workflow (Loop Cut → Inset → Extrude) can be applied to create chairs, shelves, buildings, robots, vehicles, and much more.

Quick Reference

Tool Shortcut What It Does
Extrude E Creates new geometry by pushing/pulling faces outward or inward
Inset I Creates a smaller face inside an existing face
Loop Cut Ctrl + R Adds a ring of edges to subdivide the mesh
Extrude menu Alt + E Opens advanced extrude options
Inset individual I then I Insets each selected face independently

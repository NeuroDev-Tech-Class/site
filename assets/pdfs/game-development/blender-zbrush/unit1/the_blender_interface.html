The Blender Interface

A detailed walkthrough of Blender's workspace

First Launch

When you open Blender for the first time, you'll see a splash screen with recent files and quick-start options. Click anywhere outside the splash screen to dismiss it. You'll now be looking at Blender's default workspace — and it can feel overwhelming at first. Don't worry. We'll break down every section so you know exactly what everything does.

By default, Blender starts you off with three objects already in the scene: a cube, a camera, and a light. The cube is the famous "default cube" — every Blender artist's first companion.

The Default Cube: It's a running joke in the 3D community that the first thing you do in Blender is delete the default cube. But for learning, it's actually quite useful! We'll keep it around for now.

Main Areas of the Interface

The 3D Viewport (Center)

This is the largest area and the heart of Blender. The 3D Viewport is where you see, select, move, and manipulate your 3D objects. Think of it as a window into your 3D world. You can orbit around, zoom in and out, and pan across the scene.

At the top of the viewport, you'll see a header bar with dropdown menus and a mode selector (more on modes below). At the top-right corner of the viewport, there's a small navigation gizmo — a set of colored circles representing the X, Y, and Z axes that you can click to snap to specific views.

The Toolbar (Left Side of Viewport)

On the left edge of the viewport is the Toolbar. It contains icons for common tools: Move, Rotate, Scale, and more. You can toggle the toolbar on and off by pressing T. When you select a tool here, you can use it by clicking and dragging in the viewport.

While the toolbar is helpful for beginners, most experienced Blender users rely on keyboard shortcuts instead, which are much faster. You'll learn the most important shortcuts in the next lesson.

Scene Collection / Outliner (Top Right)

The Outliner panel sits in the top-right corner and shows a hierarchical list of every object in your scene. You'll see entries like "Camera," "Cube," and "Light" listed here. This is your scene's table of contents.

You can use the Outliner to:

  • Select objects by clicking their name
  • Rename objects by double-clicking their name
  • Hide objects by clicking the eye icon next to them
  • Organize objects into collections (like folders)
Tip: Always name your objects! As your scenes grow more complex, having objects named "Cube," "Cube.001," "Cube.002" will quickly become confusing. Double-click any name in the Outliner to rename it.

Properties Editor (Bottom Right)

The Properties Editor is the tall panel on the bottom-right side of the screen. It has a row of icons along its top, each leading to a different category of settings. The most important tabs for beginners are:

  • Object Properties (orange square icon) — position, rotation, and scale of the selected object
  • Modifier Properties (wrench icon) — non-destructive operations like Subdivision Surface, Mirror, and Boolean
  • Material Properties (sphere icon) — surface colors, textures, and shader settings
  • Render Properties (camera icon) — output resolution, render engine, and quality settings

You don't need to memorize all the tabs right now. Just know that if you need to change a setting on an object, you'll likely find it somewhere in the Properties Editor.

Timeline (Bottom)

The Timeline runs along the bottom of the screen. It's primarily used for animation — setting keyframes and playing back motion over time. We won't use the Timeline much in this course since we're focused on modeling, but it's good to know it's there.

You can drag the top edge of the Timeline panel up or down to resize it. If you want more viewport space, you can shrink it down.

Header / Menu Bar (Very Top)

At the very top of the Blender window is the Header or main menu bar. It contains familiar menus like File, Edit, Render, and Window. You'll use File > Save (or Ctrl+S) frequently. You'll also find workspace tabs here (Layout, Modeling, Sculpting, etc.) that rearrange the interface for different tasks.

Object Mode vs. Edit Mode

Blender has several modes that change what you can do in the viewport. The two most important modes for modeling are:

Object Mode

This is the default mode. In Object Mode, you work with whole objects — you can select them, move them, rotate them, scale them, and organize them. You cannot modify the internal geometry (vertices, edges, faces) of an object in Object Mode.

Edit Mode

Press Tab to switch from Object Mode to Edit Mode (and press Tab again to switch back). In Edit Mode, you can see and manipulate the individual vertices, edges, and faces that make up your selected object. This is where all the detailed modeling happens.

Important: Make sure you have an object selected before pressing Tab to enter Edit Mode. If nothing is selected, nothing will happen. You can only edit one object at a time in Edit Mode.

The Three Axes

Blender uses a 3D coordinate system with three axes. Understanding these is essential for moving and placing objects precisely:

  • X axis (Red) — Left and Right
  • Y axis (Green) — Forward and Backward
  • Z axis (Blue) — Up and Down

You'll see these colors reflected throughout the interface: the gizmo arrows, the axis indicators, and the transform handles all use red, green, and blue to represent X, Y, and Z. Memorize this — it will make everything easier.

Saving Your Work

Blender saves projects as .blend files. These files contain everything about your project: all objects, materials, textures, camera settings, and more.

  • Ctrl+S — Save the current file
  • Ctrl+Shift+S — Save As (new file name or location)
Save often! Blender does have an auto-save feature, but don't rely on it. Get in the habit of pressing Ctrl+S frequently, especially before trying something experimental. You can also use File > Revert to go back to your last saved version if something goes wrong.

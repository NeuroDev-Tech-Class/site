Shading & Materials

Making your models look good with shading modes and surface materials

Viewport Shading Modes

Blender's 3D viewport can display your scene in several different ways. The viewport shading mode controls how much visual detail is shown while you work. You can switch modes using the four circle icons in the top-right of the viewport header, or by pressing Z to open the shading pie menu.

Wireframe

Shows only the edges of your objects — no surfaces, no shading. Everything is see-through. This is useful for selecting geometry that's hidden behind other parts of the mesh, or for seeing the overall structure of a complex model.

Solid

The default mode. Objects are displayed with a plain, flat shading. You can see the shape and form of your model clearly, but materials and textures are not shown. This mode is fast and reliable — you'll spend most of your modeling time here.

Material Preview

Shows objects with their assigned materials applied, using a built-in HDR environment for lighting. This lets you see colors, roughness, and metallic effects in real-time without doing a full render. Great for checking how your materials look as you set them up.

Rendered

Displays the scene as it will appear in the final render, using the active render engine (Eevee or Cycles). This is the most accurate preview but can be slower, especially with complex scenes. Use it when you want to check final lighting and material quality.

Quick access: Press Z to open the shading pie menu. Move your mouse toward the mode you want and release. This is the fastest way to switch between shading modes.

What Are Materials?

A material defines how the surface of an object looks. Without a material, an object is just a shape with the default gray color. Materials control properties like:

  • Base Color — The main color of the surface (like paint)
  • Roughness — How shiny or matte the surface is (0 = mirror-like, 1 = completely matte)
  • Metallic — Whether the surface behaves like a metal (0 = non-metal like plastic, 1 = fully metallic)
  • Specular — The intensity of reflections on non-metallic surfaces

Combining these properties allows you to simulate a huge range of real-world surfaces — from glossy red plastic to brushed aluminum to rough stone.

Adding a Material

Follow these steps to add a material to an object:

  1. Select the object in Object Mode (left-click it)
  2. Open the Properties Editor (bottom-right panel)
  3. Click the Material Properties tab (the sphere icon)
  4. Click the New button to create a new material
  5. A material slot appears with a default name like "Material." You can rename it by clicking the name field.

Setting the Base Color

Once a material is created, you'll see a Base Color field near the top of the material settings. Click the white rectangle next to "Base Color" to open the color picker. Choose any color you like. Switch to Material Preview mode (Z → Material Preview) to see the color applied to your object.

Adjusting Roughness and Metallic

Below the Base Color, you'll find sliders for Roughness and Metallic. Experiment with these:

  • Set Metallic to 1.0 for a shiny metal look
  • Set Roughness to 0.0 for a mirror-smooth surface
  • Set Roughness to 1.0 for a completely matte, rough surface
  • Set Metallic to 0.0 with low Roughness for a glossy plastic look
Tip: You need to be in Material Preview or Rendered shading mode to see material changes in the viewport. In Solid mode, you'll only see the plain gray shading.

Multiple Materials on One Object

You can assign different materials to different faces of the same object:

  1. Create multiple material slots by clicking the + button in the Material Properties panel
  2. Enter Edit Mode (Tab)
  3. Switch to Face select mode (3)
  4. Select the faces you want to assign a specific material to
  5. In the material list, select the material you want
  6. Click Assign

This is how you can have, for example, a table with a brown wooden top and black metal legs — all as a single object.

The Shader Editor (Advanced)

For more complex materials (textures, patterns, transparency, glow effects), Blender has a node-based Shader Editor. You can access it by switching to the Shading workspace tab at the top of the screen.

The Shader Editor uses a visual node system where you connect blocks (nodes) together to build complex material effects. We won't dive deep into this in Unit 1, but it's good to know it exists for when you're ready to create more advanced materials.

UV Unwrapping (Brief Overview)

If you want to apply an image texture (like a wood grain photo or a brick pattern) to a 3D model, you need to "unwrap" the 3D surface into a flat 2D layout. This process is called UV unwrapping. Think of it like cutting open a cardboard box and flattening it out — the flat version is the UV map, and you can paint or place images on it.

UV unwrapping is a more advanced topic that we'll explore later. For now, using solid colors and basic material properties is more than enough to make your models look great.

Blender & ZBrush Mini

Export & Roundtrip

Moving Your Sculpt from ZBrushCoreMini to Blender and Beyond

Why Roundtrip?

ZBrushCoreMini is an amazing sculpting tool, but it's not designed for everything. It can't add mechanical parts like pendant loops, flatten a base precisely, or prepare a model for the slicer with fine control. That's where Blender comes in. By exporting from ZBrush and importing into Blender, you get the best of both worlds: organic sculpting and precise polygon modeling.

This workflow — sculpt in ZBrush, refine in Blender, export for printing — is called a roundtrip, and it's extremely common in the professional 3D world.

Step 1: Export from ZBrushCoreMini

  1. Finish your sculpt and make sure you're happy with it (save your project first!).
  2. Click the Printer Export icon (🖨️) in the ZBrushCoreMini interface.
  3. Choose a save location and filename. The file will be saved as an OBJ (Wavefront Object) file.
  4. Click Save. The export includes the full mesh geometry of your sculpt.

Note: ZBrushCoreMini exports can only produce OBJ files. This is perfectly fine — Blender reads OBJ files without any issues.

Step 2: Import into Blender

  1. Open Blender and delete the default cube (or start a new file).
  2. Go to File → Import → Wavefront (.obj).
  3. Navigate to the OBJ file you exported from ZBrushCoreMini and select it.
  4. Click Import OBJ.
  5. Your sculpt will appear in the 3D viewport. It might be very large or very small — don't worry, you'll scale it in the next step.

About the Imported Mesh

When you import a ZBrush sculpt, you'll notice something immediately: the mesh is very dense. A typical ZBrushCoreMini export might have hundreds of thousands — or even millions — of tiny triangular faces. This is normal. ZBrush sculpts at very high polygon counts to capture fine surface detail, unlike Blender's low-poly modeling approach.

For 3D printing, this high polygon count is actually fine — the slicer can handle dense meshes. But it can make Blender feel sluggish. If your computer slows down significantly, you can use Blender's Decimate modifier to reduce the polygon count (but be aware this may lose some fine detail).

Step 3: Basic Cleanup in Blender

Positioning

Your imported sculpt may not be centered or oriented correctly. Use the following to fix it:

  • G key to grab and move the object. Press G then X, Y, or Z to constrain movement to a specific axis.
  • R key to rotate. Press R then an axis key to rotate around that axis.
  • Center the object on the origin: Right-click → Set Origin → Origin to Geometry.

Scaling

ZBrushCoreMini exports don't always match real-world dimensions. You'll need to scale the model to the correct size for printing:

  • Press S to scale, then type a number to scale by a factor (e.g., S → 0.1 to shrink to 10% size).
  • Check dimensions in the N panel (press N to toggle the sidebar) under the Item tab → Dimensions. These show the size in Blender units (which correspond to millimeters if your scene is set to metric).
  • After scaling, apply the scale: Ctrl + A → Scale. This resets the scale values to 1.0 while keeping the actual size, which prevents problems during export.

Step 4: Adding Geometry in Blender

This is where the roundtrip really shines. You can add precise, geometric shapes that would be difficult or impossible to sculpt in ZBrush:

Pendant Loop

To turn your sculpt into a wearable pendant, add a torus (donut shape) at the top:

  1. Press Shift + A → Mesh → Torus.
  2. Size it appropriately — the inner hole should be large enough for a chain or cord to pass through (at least 3-4mm inner diameter).
  3. Position it so it overlaps slightly with the top of your sculpt (the two meshes should intersect).
  4. Select both objects, then join them: Ctrl + J.
  5. Use a Boolean modifier (Union) if you want a cleaner merge, or simply leave them intersecting — for 3D printing, overlapping geometry usually prints fine.

Flat Base

If your sculpt needs to stand upright, add a flat base:

  1. Press Shift + A → Mesh → Cylinder.
  2. Make it short and wide (like a coin or disc).
  3. Position it at the bottom of your sculpt so it overlaps slightly.
  4. Join the objects with Ctrl + J.

Step 5: Re-Export for Printing

  1. Select your final combined object.
  2. Go to File → Export → STL (.stl).
  3. Check Selection Only in the export options.
  4. Set the Scale to 1.0 (assuming you've already sized it correctly in Blender).
  5. Export and open the STL file in your slicer software to prepare for printing.

Key Takeaways

  • Export from ZBrushCoreMini using the Printer Export icon → OBJ file.
  • Import into Blender via File → Import → Wavefront OBJ.
  • The imported mesh will be very high-poly — that's normal.
  • Use Blender to position, scale, and add geometry (loops, bases, mechanical parts).
  • Re-export as STL for 3D printing.

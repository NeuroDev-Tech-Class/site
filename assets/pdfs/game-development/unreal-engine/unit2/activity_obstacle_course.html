Activity: Obstacle Course

Build a playable platforming level using every Blueprint mechanic from Unit 2

Overview

In this activity, you'll design and build a complete obstacle course level that combines all the gameplay systems you've created so far: collectible coins, jump pads, keys, doors, and checkpoints. The goal is to create a fun, challenging experience that a player can navigate from start to finish.

This is a creative project — there's no single "correct" layout. Focus on making your course playable (can the player actually reach every platform?), fair (is there always a path forward?), and fun (does it feel good to play?).

Time estimate: This activity will take approximately 1–2 class sessions. Spend the first session on layout and placing actors; spend the second session on testing, polishing, and fixing issues.

Step 1: Create a New Level

  1. Go to File → New Level and choose Basic.
  2. Save immediately: Ctrl+Shift+S → name it ObstacleCourse.
  3. Delete the default floor if there is one — you'll build your own platforms.
  4. Add a Player Start actor and place it where you want the player to begin.

Step 2: Build the Platforms

  1. Use Static Meshes (cubes) from the StarterContent or any content pack to create platforms.
  2. Start at the Player Start location and build outward. Create platforms at varying heights — the player should need to jump between them.
  3. Mix up the sizes: some wide and easy, some narrow and tricky.
  4. Leave gaps between platforms — the player should need to jump (or use jump pads) to cross them.
  5. Create at least one section that requires the player to go upward — stacking platforms like stairs or placing them at increasing heights.
  6. Use Alt+Drag to duplicate platforms quickly.
Test as you build: Don't build the entire course and then test it for the first time. After every 4–5 platforms, press Play and try jumping through the course. This helps you catch impossible jumps early.

Step 3: Place Collectible Coins

  1. Drag at least 10 BP_Coin actors into the level.
  2. Scatter them across the course — some on platforms, some floating in the air between jumps (midair coins give the player visual targets and make jumps feel more rewarding).
  3. Place a few coins in hard-to-reach spots for bonus challenge.
  4. Make sure the player can actually reach every coin — test each one!

Step 4: Place Jump Pads

  1. Drag 2–3 BP_JumpPad actors into the level.
  2. Place them where the player needs a boost to reach a high platform that normal jumping can't reach.
  3. Test each jump pad to make sure it launches the player to the intended destination. Adjust the Launch Velocity Z value in the Blueprint if needed.
  4. Consider placing coins along the arc of the jump pad launch for a satisfying collection path.

Step 5: Add the Key and Locked Door

  1. Place one BP_Key somewhere in the course — ideally in a tricky or out-of-the-way location that rewards exploration.
  2. Place one BP_Door blocking the path to the final section of the course. The player must find the key before they can pass through.
  3. Make sure the player can still reach the key location from where the door is — don't accidentally create a dead end where finding the key requires passing through the door.

Step 6: Set Up Checkpoints

  1. Place at least 2 BP_Checkpoint actors at milestone locations along the course (e.g., one after the first major jump section, one before the door).
  2. If you haven't created BP_Checkpoint yet, refer to the Win, Lose & Checkpoints lesson to build one. At minimum, it should save the player's current location so they can respawn there.
  3. Test that each checkpoint updates the spawn point correctly.

Step 7: Create the Victory Area

  1. After the locked door, create a final area — a platform or room that represents the finish line.
  2. Place a BP_Win actor here. When the player enters its collision, they should see a "You Win!" message (or a victory UI widget if you've built one).
  3. Optionally, decorate this area to make it feel like a reward — add lights, a different material, or extra visual flair.

Step 8: Play-Test the Full Course

  1. Press Play and run through the entire course from start to finish.
  2. Check for:
    • Impossible jumps — can you physically reach every platform?
    • Missing collisions — can you walk through any platforms unexpectedly?
    • Coin count — does the counter increment properly for every coin?
    • Key/Door system — does the door block you without the key and open with it?
    • Checkpoints — if you fall, do you respawn at the right location?
    • Win condition — does the victory trigger fire at the end?
  3. Fix any issues and test again. A good game developer play-tests dozens of times.

Completion Checklist

Requirements — check off each item before submitting:
✓ Requirement
☐ New level created and saved as ObstacleCourse
☐ Platforms built at varying heights with clear jump paths
☐ At least 10 BP_Coin actors placed and collectible
☐ At least 2 BP_JumpPad actors placed and functional
☐ 1 BP_Key placed in a challenging location
☐ 1 BP_Door blocking access to the final area — unlockable with the key
☐ At least 2 BP_Checkpoint actors placed at milestone locations
☐ 1 BP_Win actor in the victory area that triggers a win message
☐ Player Start placed at the beginning of the course
☐ Full course play-tested and completable from start to finish
☐ Level saved (Ctrl+S)
Going Further: If you finish early, try adding moving platforms (use a Timeline node to animate a platform's location), hazards the player must avoid, or a coin counter displayed on screen. You can also decorate your course with lights, materials, and particle effects.

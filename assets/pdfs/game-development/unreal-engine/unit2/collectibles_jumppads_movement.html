Collectibles, Jump Pads & Movement

Build coins the player can collect, pads that launch them skyward, and enable double jump

Creating Collectible Coins (BP_Coin)

Coins are one of the most classic game mechanics — the player walks into a coin, it disappears, and their score goes up. Let's build that as an Actor Blueprint.

Setting Up the Blueprint

  1. In the Content Browser, right-click → Blueprint Class → Actor. Name it BP_Coin.
  2. Open BP_Coin and add the following components:
    • Sphere Collision — make this the root component. Set Sphere Radius to about 80.
    • Static Mesh — add as a child of the Sphere Collision. Use the default Sphere mesh. Scale it down to around (0.5, 0.5, 0.1) so it looks like a flat coin, or use (0.3, 0.3, 0.3) for a round orb.
  3. Change the mesh material to something gold or bright yellow — drag a gold-colored material onto the Static Mesh in the viewport, or set it in the Details panel under Materials.

Optional: Make It Spin

  1. Add a Rotating Movement component (search for it in the Add Component menu).
  2. In its Details panel, set the Rotation Rate — for example, Z: 180 will make it spin smoothly around the vertical axis.
  3. The coin will now rotate automatically during gameplay, no Blueprint logic needed.

Optional: Add a Glow

  1. Add a Point Light or Spot Light component as a child.
  2. Set the light color to yellow/gold and reduce the Intensity and Attenuation Radius so it creates a subtle glow around the coin rather than lighting up the whole room.

Coin Pickup Logic

Now let's make the coin do something when the player touches it.

  1. Select the Sphere Collision component. Set its Collision Presets to OverlapAllDynamic and ensure Generate Overlap Events is checked.
  2. Add an On Component Begin Overlap event (Details panel → Events → click +).
  3. In the Event Graph, drag from Other Actor and add a Cast To BP_ThirdPersonCharacter.
  4. From the character output pin, drag and search for Set CoinCount. (You'll need to add an Integer variable called CoinCount to your player character Blueprint first, with a default value of 0.)
  5. Before the Set node, add a Get CoinCount node and connect it to an Integer + Integer node. Add 1 to the current count, then wire the result into the Set node.
  6. After the Set node, add a Destroy Actor node to remove the coin from the level.
Test it: Place a few BP_Coin actors in your level, press Play, and walk into them. Add a Print String after the Set to display the current CoinCount and verify it increments correctly.

Jump Pad (BP_JumpPad)

Jump pads launch the player into the air when they land on them — perfect for reaching high platforms.

Setting Up the Blueprint

  1. Create a new Actor Blueprint named BP_JumpPad.
  2. Add a Static Mesh component. Use a Cylinder mesh and scale it to be short and wide (e.g., Scale X: 2, Y: 2, Z: 0.2) so it looks like a platform pad.
  3. Change its material to something eye-catching — bright green, glowing blue, or anything that says "step on me!"
  4. Make sure the Static Mesh has Simulation Generates Hit Events enabled in the Details panel under Collision.
  5. The collision preset should be set to BlockAllDynamic so the player can physically land on it.

Launch Logic

  1. Select the Static Mesh component and add an On Component Hit event (Details → Events → click + next to On Component Hit).
  2. In the Event Graph, drag from the Other Actor pin and add a Cast To Character node. (We use "Character" instead of the specific player class so it works with any character type.)
  3. From the cast output, add a Launch Character node.
  4. Set the Launch Velocity: X: 0, Y: 0, Z: 1000. This launches the player straight up. Increase Z for a higher launch.
  5. Make sure Override XY Velocity and Override Z Velocity are both checked — if not, the launch may not feel consistent.
  6. Compile, save, place a BP_JumpPad in your level, and test!
Fine-tuning: A Z value of 1000 gives a moderate launch. Try 1500 or 2000 for bigger jumps. You can also add X or Y values to create directional launchers that throw the player forward.

Double Jump

Enabling double jump is surprisingly simple in Unreal Engine because the Character class already has the feature built in — you just need to enable it.

  1. Open your player character Blueprint (BP_ThirdPersonCharacter or whatever your character class is named).
  2. In the Components panel, select the CharacterMovement component.
  3. In the Details panel, search for Jump Max Count.
  4. Change it from 1 to 2.
  5. Compile, save, and play — press the jump button twice to double jump!
That's it: No extra Blueprint logic needed. Unreal's Character Movement component handles multi-jump automatically. Set it to 3 for a triple jump, or even higher for testing. Just don't forget to set it back to something reasonable before your final build!

Summary

  • BP_Coin — Sphere mesh + Sphere Collision. On overlap: Cast to player, increment CoinCount, Destroy Actor. Optional: Rotating Movement and Point Light for polish.
  • BP_JumpPad — Cylinder mesh with Hit events. On hit: Cast to Character, Launch Character with a high Z velocity.
  • Double Jump — set Jump Max Count to 2 on the CharacterMovement component. Done.
  • These mechanics are the building blocks of platformer gameplay — combine them with keys, doors, and level design to create full game experiences.

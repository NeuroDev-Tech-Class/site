Variables, Branches & Functions

Store data, make decisions, and organize your Blueprint logic

Variables in Blueprints

A variable is a named container that holds a piece of data. Just like a labeled box — you give it a name, choose what type of thing goes inside, and then you can read from it or change its contents whenever you need to.

Variable Types

Every variable in Blueprints has a type that determines what kind of data it can store:

Type Color What It Stores Example
Boolean Dark Red True or False HasKey = True
Integer Teal Whole numbers CoinCount = 5
Float Light Green Decimal numbers Speed = 600.0
String Magenta Text PlayerName = "Alex"
Vector Yellow X, Y, Z values SpawnPoint = (0, 0, 100)

Creating a Variable

  1. Open a Blueprint (Level Blueprint or an Actor Blueprint).
  2. In the My Blueprint panel on the left, find the Variables section.
  3. Click the + Variable button.
  4. Give it a name (e.g., TotalGold).
  5. In the Details panel on the right, set the Variable Type (e.g., Integer).
  6. Optionally set a Default Value — you may need to compile first before the default value field appears.

Get and Set Nodes

Once you've created a variable, you interact with it using two types of nodes:

  • Get — reads the current value. Drag the variable from the My Blueprint panel into the Event Graph, or hold Ctrl and drag it. This creates a Get node.
  • Set — changes the value. Hold Alt and drag the variable into the graph. This creates a Set node with an execution pin (because changing data is an action that happens in sequence).
Remember: Ctrl+Drag = Get (read). Alt+Drag = Set (write). You'll use this constantly.

The Branch Node (If/Then Logic)

The Branch node is Blueprints' version of an if/then statement. It takes a Boolean (true/false) input and splits the execution into two paths:

  • True — this path executes if the condition is true.
  • False — this path executes if the condition is false.

To add one, right-click the Event Graph and search for Branch. Connect a Boolean value to the Condition pin. Then wire different actions to the True and False outputs.

Keyboard Input Events

You can listen for keyboard presses in the Level Blueprint. Right-click the Event Graph and search for the key name — for example, N. Select Keyboard Events → N. This creates a node with Pressed and Released execution pins. You can do the same for any key: G, E, Space Bar, etc.

Building a Gold System

Let's put variables, input, and branches together by building a simple gold-collecting system in the Level Blueprint.

Step 1: Create the Variables

  1. Open the Level Blueprint (Blueprints toolbar → Open Level Blueprint).
  2. Create an Integer variable called TotalGold. Set its default value to 0.
  3. Create another Integer variable called GainGold. Set its default value to 10.

Step 2: Add Gold on Key Press

  1. Right-click the Event Graph and add a Keyboard Event for the G key.
  2. From the Pressed pin, drag out a wire and add a Get TotalGold node and a Get GainGold node.
  3. Add an Integer + Integer node (search for "int + int" or just "+"). Connect TotalGold and GainGold to its inputs.
  4. Add a Set TotalGold node. Connect the output of the addition to the input of the Set node.
  5. Add a Print String node after the Set node. To print the new gold total, you'll need to right-click the integer output and select Convert to String, or use an Append String node to combine text like "Gold: " with the number.

Step 3: Check a Threshold with Branch

  1. After the Print String, add a Branch node.
  2. Add an Integer >= Integer node (search for ">="). Connect TotalGold to the top input and type 100 in the bottom input.
  3. Connect the Boolean output of the >= node to the Condition pin of the Branch.
  4. On the True path, add a Print String: "You have enough gold to buy the sword!"
  5. Compile and play — press G repeatedly to gain gold and watch the messages change when you hit 100!
Experiment: Try changing GainGold's default value to different amounts. Try adding a second key (N) that subtracts gold. What happens if TotalGold goes below zero?

Functions

As your Blueprint grows, you'll find yourself repeating the same set of nodes in multiple places. Functions let you bundle a group of nodes into a single reusable block — like creating your own custom node.

Creating a Function

  1. In the My Blueprint panel, find the Functions section and click + Function.
  2. Name it AddGold.
  3. A new graph tab opens — this is the function's own mini Event Graph.
  4. You'll see a purple entry node at the left. This is where execution enters the function.

Parameters (Inputs)

Functions can accept inputs (parameters) — data you pass in when you call the function.

  1. Select the purple entry node.
  2. In the Details panel, click the + button next to Inputs.
  3. Name the input Amount and set its type to Integer.
  4. Now build the addition logic inside the function: Get TotalGold → add Amount → Set TotalGold.

Return Values (Outputs)

Functions can also return data (outputs).

  1. Select the purple entry node again.
  2. Click the + button next to Outputs.
  3. Name the output NewTotal and set its type to Integer.
  4. A Return Node appears at the end of the function graph. Connect the updated TotalGold value to the NewTotal output pin.

Calling the Function

Back in the main Event Graph, right-click and search for AddGold — your custom function appears! Place it and connect the execution pin. Pass in a value for Amount (e.g., 10). The function handles all the internal logic.

Functions don't support latent actions: You cannot use Delay, timelines, or other time-based nodes inside functions. If you need time-based logic, use the Event Graph directly or use a Macro instead.

Organization Tips

Comment Boxes

Select a group of nodes and press C to wrap them in a labeled comment box. Use descriptive names like Gold System — Add on G Press or Branch — Check Gold Threshold. Color-code them for quick visual identification.

Reroute Pins

When wires cross over each other and create a tangled mess, add reroute nodes. Double-click on any wire to add a reroute pin — a small dot that you can drag to redirect the wire's path. This keeps your graph clean and readable.

Summary

  • Variables store data — Booleans, Integers, Floats, Strings, Vectors.
  • Use Get (Ctrl+Drag) to read and Set (Alt+Drag) to write.
  • The Branch node splits execution based on a true/false condition.
  • Keyboard events let you respond to key presses.
  • Functions bundle reusable logic with inputs (parameters) and outputs (return values).
  • Keep your graphs clean with comment boxes and reroute pins.

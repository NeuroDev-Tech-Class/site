UMG Widgets & HUD

Create on-screen UI elements using Unreal Motion Graphics and display a live coin counter

What Is UMG?

UMG stands for Unreal Motion Graphics — it's Unreal Engine's built-in system for creating user interfaces. Anything the player sees on screen that isn't part of the 3D world — health bars, score displays, menus, dialogue boxes, inventory screens — is built with UMG.

UMG uses Widget Blueprints, which are a special type of Blueprint designed specifically for UI. Instead of an Event Graph with 3D actors, you work with a visual designer where you drag and drop 2D elements like text labels, images, buttons, and progress bars.

Creating a Widget Blueprint

  1. In the Content Browser, right-click → User Interface → Widget Blueprint.
  2. Name it HUD_Coin (this widget will display the player's coin count).
  3. Double-click to open it. You'll see the UMG Designer — a preview screen that represents the player's view.

The Canvas Panel

Every Widget Blueprint starts with a Canvas Panel as the root element. The Canvas Panel is a container that lets you position child widgets anywhere on screen using anchors. Think of it as the "page" your UI elements sit on.

You should see the Canvas Panel listed in the Hierarchy panel on the left. All your UI elements will be children of this Canvas Panel.

Adding UI Elements

The Palette panel (usually on the left side) contains all available UI widgets. Drag them into the Designer viewport or into the Hierarchy panel to add them.

Common UI Elements

Widget Purpose
Text Displays text on screen — labels, scores, messages
Image Displays a 2D image — icons, backgrounds, frames
Horizontal Box Arranges child widgets in a horizontal row
Vertical Box Arranges child widgets in a vertical column
Progress Bar A fill bar — great for health, stamina, loading
Button A clickable element for menus and interaction

Anchoring Widgets

Every widget on a Canvas Panel has an anchor — this controls where the widget is positioned relative to the screen. Anchors are critical because players have different screen sizes and resolutions.

  • Top-Left anchor: The widget stays near the top-left corner regardless of screen size. Great for score counters and health bars.
  • Center anchor: The widget stays centered on screen. Good for "Game Over" text or crosshairs.
  • Bottom-Center anchor: Good for ability bars or quick-use slots.

To set an anchor: select the widget, and in the Details panel look for the Anchors dropdown (it shows a visual grid). Click the anchor position you want. A flower-shaped icon appears in the Designer showing the anchor point.

Rule of thumb: Always anchor your widgets to the corner or edge they're closest to. A coin counter in the top-left should be anchored to the top-left. If you don't, your UI will look correct on your screen but may be off-screen or misplaced on a different resolution.

Building the HUD_Coin Widget

Let's create a simple HUD that shows "Coins: 5" (or whatever the current count is) in the top-left corner of the screen.

Step 1: Layout

  1. Open your HUD_Coin Widget Blueprint.
  2. From the Palette, drag a Horizontal Box onto the Canvas Panel. This will hold our label and number side by side.
  3. Set the Horizontal Box's anchor to Top-Left.
  4. Position it with some padding from the edges (e.g., Position X: 20, Position Y: 20).
  5. Inside the Horizontal Box, add two Text widgets:
    • First Text: set its text to Coins: (with a space after the colon). This is the static label.
    • Second Text: leave it as the default "Text Block" for now — we'll bind it to the coin count dynamically.
  6. Style the text: in the Details panel for each Text widget, set the Font Size to 24 or larger, and optionally change the Color to gold or white so it's easily readable.

Step 2: Binding the Coin Count

The second Text widget needs to display the player's current CoinCount value — and it needs to update dynamically as coins are collected.

  1. Select the second Text widget in the Hierarchy.
  2. In the Details panel, find the Text property. Next to it, click the Bind dropdown → Create Binding.
  3. This creates a new function (it opens automatically). This function runs every frame and whatever it returns becomes the displayed text.
  4. Inside the binding function:
    • Add a Get Player Character node (this returns the player).
    • Drag from the output and add a Cast To BP_ThirdPersonCharacter.
    • From the cast output, drag and add a Get CoinCount node.
    • The CoinCount is an Integer, but the text binding expects a Text type. Drag from the integer pin to the Return Value pin — Unreal will automatically add a conversion node.
  5. Compile and save the widget.
Performance note: Bindings run every frame, which can be expensive if you have many of them. For a simple coin counter this is perfectly fine. In larger projects, you may want to use event-driven updates instead (only update the text when a coin is actually collected).

Adding the Widget to the Viewport

Creating the widget isn't enough — you need to tell the game to actually display it on screen. We'll do this in the player character Blueprint on BeginPlay.

  1. Open your player character Blueprint (BP_ThirdPersonCharacter).
  2. In the Event Graph, find or add an Event BeginPlay node.
  3. Drag from the execution pin and add a Create Widget node. In the Class dropdown, select HUD_Coin.
  4. Drag from the Return Value output and add an Add To Viewport node.
  5. Connect the execution pins: BeginPlay → Create Widget → Add To Viewport.
  6. Compile and save.

Now when you press Play, the coin counter appears in the top-left corner and updates live as you collect coins!

Troubleshooting: If the widget doesn't appear, make sure the Create Widget's Owning Player pin is connected (drag off BeginPlay's output and get Get Owning Player, or leave it as default for single-player games). Also verify you selected the correct widget class in the dropdown.

Summary

  • UMG (Unreal Motion Graphics) is the system for creating 2D user interfaces.
  • Widget Blueprints let you design UI elements visually using a Canvas Panel.
  • Common widgets: Text, Image, Horizontal/Vertical Box, Progress Bar, Button.
  • Anchors control where widgets appear relative to the screen — always match the anchor to the widget's position.
  • Use Bindings to make text display dynamic data like coin counts.
  • Display a widget with Create Widget → Add To Viewport on BeginPlay.

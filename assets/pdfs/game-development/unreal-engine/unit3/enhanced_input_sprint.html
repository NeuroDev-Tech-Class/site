Enhanced Input & Sprint

Use UE5's Enhanced Input system to add a sprint mechanic with keyboard and gamepad support

What Is Enhanced Input?

Unreal Engine 5 uses the Enhanced Input system — a modern, flexible way to handle player input. Instead of directly checking "is the W key pressed?", you define abstract Input Actions like "Sprint" or "Jump" and then map physical keys/buttons to those actions separately. This makes it easy to support multiple input devices (keyboard, gamepad, etc.) without duplicating logic.

Key Concepts

Input Actions (IA)

An Input Action represents what the player wants to do — not which button they pressed. For example:

  • IA_Sprint — the player wants to sprint
  • IA_Jump — the player wants to jump
  • IA_Interact — the player wants to interact with an object

Each Input Action has a Value Type (Boolean for on/off, Axis1D for analog triggers, etc.) and can have Triggers that define when the action fires:

  • Down — fires while the key is held down (continuous)
  • Pressed — fires once when the key is first pressed
  • Released — fires once when the key is let go
  • Hold — fires after the key is held for a specified duration

Input Mapping Contexts (IMC)

An Input Mapping Context is where you map physical inputs (keys, buttons, sticks) to your Input Actions. Think of it as a binding table:

Input Action Key/Button
IA_Sprint Left Shift, Gamepad Right Trigger
IA_Jump Space Bar, Gamepad Bottom Face Button
IA_Interact E, Gamepad Left Face Button

You can have multiple IMCs — for example, one for on-foot gameplay and a different one for driving. Swap them at runtime to completely change the controls.

Why this separation matters: Input Actions define what happens. Input Mapping Contexts define which buttons trigger it. This means you can change key bindings without touching any game logic, and you can support keyboard + gamepad simultaneously with zero extra code.

Creating IA_Sprint

  1. In the Content Browser, right-click → Input → Input Action. Name it IA_Sprint.
  2. Double-click to open it.
  3. Set the Value Type to Digital (Bool) — sprinting is either on or off.
  4. Under Triggers, add two entries:
    • Hold — the sprint action fires while the key is held down. You can set the Hold Time Threshold to 0 for instant activation (no delay before sprinting starts).
    • Released — this fires when the key is released, which we'll use to stop sprinting.
  5. Save the asset.

Adding to the Input Mapping Context

  1. Open your project's Input Mapping Context (the Third Person template usually has one called IMC_Default in the Input folder).
  2. Click the + button to add a new mapping.
  3. Set the Input Action to IA_Sprint.
  4. Under this action, add two key mappings:
    • Left Shift — for keyboard players
    • Gamepad Right Trigger — for controller players
  5. Save the IMC.

Implementing Sprint in the Player Character

Now we need to make the character actually sprint when the input fires.

  1. Open your player character Blueprint (BP_ThirdPersonCharacter).
  2. In the Event Graph, right-click and search for IA_Sprint. You'll see an Enhanced Input Action event node — add it.
  3. This node has multiple execution pins based on your triggers:
    • Triggered — fires while the key is held (from our Hold trigger)
    • Completed — fires when the key is released (from our Released trigger)

SprintStart Function

  1. Create a new function called SprintStart.
  2. Inside the function, drag a reference to the CharacterMovement component.
  3. From it, add a Set Max Walk Speed node.
  4. Set the value to 1200 (Unreal's default walk speed is 600, so 1200 is double speed).
  5. Connect the execution from the function entry to the Set node.

SprintStop Function

  1. Create another function called SprintStop.
  2. Same as above, but set Max Walk Speed back to 600 (the default).

Connecting the Input

  1. Back in the Event Graph, connect the Triggered pin from the IA_Sprint event to your SprintStart function call.
  2. Connect the Completed pin to your SprintStop function call.
  3. Compile and save.

That's it! Press Play, hold Left Shift, and your character should move noticeably faster. Release the key and they'll return to normal speed.

Fine-tuning: A sprint speed of 1200 feels like a solid run. Try values between 900 (light jog) and 1500 (very fast) to find what feels right for your game. You can also add a sprint cooldown or stamina system later.

Optional: IsSprinting Boolean for Animation

If you want the character's animation to change while sprinting (e.g., a faster run animation), you'll need a way for the Animation Blueprint to know whether the player is currently sprinting.

  1. Add a Boolean variable to your character Blueprint called IsSprinting. Default: false.
  2. In your SprintStart function, add a Set IsSprinting node and set it to True.
  3. In your SprintStop function, add a Set IsSprinting node and set it to False.
  4. In the Animation Blueprint, you can now read IsSprinting from the character and use it to blend to a sprint animation.
Don't worry about the Animation Blueprint for now — animation is an advanced topic. The IsSprinting variable is useful to set up now so it's ready when you learn animation blending later.

Summary

  • UE5's Enhanced Input system separates actions (what the player does) from mappings (which buttons they press).
  • Input Actions (IA) define abstract actions with triggers like Hold and Released.
  • Input Mapping Contexts (IMC) map physical keys/buttons to Input Actions.
  • Sprint is implemented by changing Max Walk Speed on the CharacterMovement component: 1200 for sprinting, 600 for walking.
  • An optional IsSprinting Boolean can be used later for animation blending.

Meshes, Transforms & Materials

Learn how to place 3D objects, position them precisely, and control how their surfaces look

Static Meshes

A Static Mesh is a pre-made 3D model that doesn't have a skeleton or built-in animation — think walls, floors, rocks, crates, pillars, and furniture. "Static" doesn't mean it can't move at runtime (physics can move it), it just means the geometry itself doesn't deform like a character would.

Static Meshes are the fundamental building blocks of every environment in Unreal Engine. A typical game level might contain hundreds or even thousands of them.

Finding Meshes in the Content Browser

To find meshes you can use:

  1. Open the Content Browser (Ctrl+Space).
  2. Navigate to a folder that contains meshes — if you're using a template project, check Content → StarterContent → Props or Content → StarterContent → Architecture.
  3. Use the Filters button and select Static Mesh to only show mesh assets.
  4. You can also type a name in the search bar (e.g., "wall" or "rock").

Placing Meshes in the Level

There are two ways to add a mesh to your level:

  • Drag and Drop: Click a mesh in the Content Browser and drag it directly into the Viewport. Release the mouse button to place it.
  • Quick Add: Click the + (Quick Add) button in the toolbar, or right-click in the Viewport → Place Actors to browse a catalog of common actors.
Tip: When you drag a mesh into the Viewport, it will automatically snap to the surface below your cursor. If you want to place it at a specific height, hold Shift before releasing or manually set the Z position in the Details Panel afterward.

Transform Tools

Once an actor is in the level, you'll need to position, rotate, and size it. Unreal provides three transform tools, each activated by a single key:

Tool Key Use Case
Move W Slide the actor along X, Y, or Z axes
Rotate E Spin the actor around an axis
Scale R Stretch or shrink the actor along one or more axes

You can also type exact values in the Details Panel under the Transform section. This is essential when you need pixel-perfect alignment — for example, setting a wall's X position to exactly 500.0 or rotating a pillar exactly 90°.

Snapping for Precision

Enable Grid Snap in the Viewport toolbar (the magnet icon) to force objects to move in fixed increments. Common grid sizes:

  • 10 units — Good for general layout and rough placement.
  • 5 units — Tighter alignment for architectural pieces.
  • 1 unit — Fine adjustments.
  • 100 units — Quick, large-scale building (each unit ≈ 1 cm, so 100 = 1 meter).

Similarly, enable Rotation Snap (default 10°) to keep angles consistent, and Scale Snap for uniform sizing.

Tip: Remember that Alt + Drag (with the Move tool active) duplicates the selected actor. This is the fastest way to build a row of identical objects — duplicate one, then duplicate the duplicate, and so on.

Materials

A Material defines how a surface looks — its color, roughness, shininess, transparency, and more. Without materials, every mesh would be a featureless gray blob. Materials are what make stone look like stone, metal look like metal, and glass look like glass.

How Materials Work

In Unreal Engine, materials are built from a combination of:

  • Textures — 2D images that provide color (diffuse/albedo), surface detail (normal maps), and other surface information.
  • Parameters — Numeric values that control properties like roughness (how shiny vs. matte the surface is), metallic (metal vs. non-metal), and emissive (does it glow?).
  • Shader logic — Nodes in the Material Editor that define how all of this data is combined.

Applying Materials to Meshes

There are several ways to apply a material:

  1. Drag and drop: Find a material in the Content Browser, then drag it directly onto a mesh in the Viewport. The mesh will update immediately.
  2. Details Panel: Select a mesh, then in the Details Panel scroll down to the Materials section. Each Element slot represents a material applied to a different part of the mesh. Click the dropdown or the browse button to choose a different material.
Tip: Some meshes have multiple material slots (elements). For example, a table might have one slot for the wood surface and another for the metal legs. You can assign different materials to each slot.

The Material Editor (Preview)

For custom materials, you'll use the Material Editor — a node-based visual editor where you connect texture samples, math nodes, and parameter nodes to build exactly the look you want. To open it, double-click any material asset in the Content Browser.

We'll explore the Material Editor in depth in a later unit. For now, focus on using the pre-made materials that come with your project or content packs.

Note: If a mesh appears with a black-and-white checkerboard pattern, that means it's missing its material. Drag a material onto it or assign one through the Details Panel.

The Player Start Actor

The Player Start actor is a special actor that determines where the player spawns when you press Play. Every playable level needs one.

  • Find it in the Quick Add menu (+ → Basic → Player Start) or search for "Player Start" in the Content Browser's Place Actors panel.
  • Position it where you want the player to appear — typically on a flat surface with enough room to stand.
  • The blue arrow on the Player Start shows the direction the player will face when the game begins.
  • If the Player Start icon appears as a red icon with a warning, it means it's colliding with something or is stuck inside geometry — move it to open space.
Practice: In your project, do the following:
  1. Open the Content Browser and find a static mesh (a wall, pillar, or prop).
  2. Drag it into the Viewport and position it using the Move tool (W).
  3. Rotate it 45° using the Rotate tool (E).
  4. Scale it up to 2x using the Scale tool (R) or by setting Scale to 2.0, 2.0, 2.0 in the Details Panel.
  5. Find a material and drag it onto the mesh to change its appearance.
  6. Place a Player Start near the mesh, press Play, and walk up to your object.

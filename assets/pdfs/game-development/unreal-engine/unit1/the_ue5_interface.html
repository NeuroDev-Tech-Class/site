Intro to Unreal Engine

The UE5 Interface

A complete walkthrough of every major panel in the Unreal Engine 5 editor

First Launch

When you open a project in Unreal Engine 5, you're greeted by the Level Editor — the main workspace where you build, test, and iterate on your game. At first glance it can feel overwhelming: there are panels, menus, and buttons everywhere. Don't worry. By the end of this lesson, you'll know exactly what each piece does and how to make the editor work for you.

Tip: If you ever accidentally close a panel, you can reopen it from the Window menu in the top menu bar. You can also reset the entire layout to the default by going to Window → Load Layout → Default Editor Layout.

The Core Panels

1. The Viewport

The Viewport is the large 3D view that dominates the center of the screen. This is your window into the game world — it shows you exactly what your level looks like in real time. You can fly around, select objects, move things, and even preview lighting and effects right here.

Key things to know about the Viewport:

  • It renders in real time, so changes you make are instantly visible.
  • The top-left corner has a dropdown for view modes (Lit, Unlit, Wireframe, etc.) that let you see your level in different ways — useful for debugging lighting or performance issues.
  • You can have multiple viewports by clicking the viewport options menu (small arrow in the top-left) and selecting a multi-viewport layout.
  • The small icons in the top-left also let you toggle things like real-time rendering, grid snapping, and camera speed.

2. The Content Browser

The Content Browser (sometimes called the Content Drawer in UE5) is essentially a file manager for your project. Every asset your project uses — 3D models (meshes), textures, materials, sounds, Blueprints, animations, particle effects — lives in the Content Browser.

  • Open it with Ctrl+Space (Content Drawer) or find it under Window → Content Browser.
  • Assets are organized into folders, just like files on your computer.
  • You can drag and drop assets directly from the Content Browser into the Viewport to place them in your level.
  • Right-click inside it to create new assets like materials, Blueprints, and folders.
  • Use the search bar at the top to quickly find assets by name.
  • The Filters button lets you narrow results to specific asset types (e.g., show only Static Meshes or only Materials).
Tip: If you're using a template project, check the StarterContent folder — it comes packed with free meshes, materials, textures, and props you can use right away.

3. The Details Panel

When you select any object (called an Actor) in the Viewport or Outliner, its properties appear in the Details Panel, typically located on the right side of the editor. This is where you fine-tune everything about that object:

  • Transform — Position (Location), Rotation, and Scale values. You can type exact numbers here for precision placement.
  • Materials — Which material(s) are applied to the mesh.
  • Mobility — Whether the actor is Static (never moves), Stationary (stays put but can change), or Movable (fully dynamic).
  • Physics — Enable or disable physics simulation, set mass, gravity, etc.
  • Components — Every actor is made up of components (mesh, collision, audio, etc.). You can add, remove, and configure them here.
  • Tags & Layers — Organize actors with tags for use in gameplay logic.

The Details Panel is context-sensitive: it changes based on what you have selected. Select a light and you'll see light-specific settings like intensity and color. Select a sound and you'll see audio settings.

4. The Outliner

The Outliner (usually in the upper-right corner) is a hierarchical list of every single actor in your current level. Think of it as a table of contents for your scene.

  • Click an actor's name to select it (it will also highlight in the Viewport).
  • Use the search bar to find actors by name.
  • You can drag actors onto other actors to create parent-child relationships (attaching objects together).
  • Click the eye icon next to an actor to toggle its visibility in the editor (this does not affect the game).
  • Right-click actors to rename, duplicate, group, or delete them.
  • Keep your Outliner organized by creating folders — right-click and choose Create Folder.
Warning: A messy Outliner will slow you down as your project grows. Get into the habit of naming your actors descriptively (e.g., "CastleWall_Left_01" instead of "SM_Wall3") and organizing them into folders early.

5. The Toolbar

The Toolbar runs along the top of the editor and contains the most frequently used actions:

Button What It Does
Save Current Saves the current level (Ctrl+S)
Save All Saves all modified assets
Play Launches the game in the viewport for testing (Alt+P)
Blueprints Quick access to the Level Blueprint and other Blueprint editors
Build Bakes lighting, navigation meshes, and other pre-computed data
Settings Project Settings, World Settings, and editor preferences
Platforms Configure and package your game for different platforms

6. The Modes Panel

The Modes Panel (accessed via the selection mode dropdown on the left side of the toolbar, or the icons on the left edge) switches the editor between different editing modes:

  • Select Mode — The default. Select and move actors in the Viewport.
  • Landscape Mode — Create and sculpt terrain.
  • Foliage Mode — Paint trees, grass, and other foliage onto surfaces.
  • Mesh Paint Mode — Paint vertex colors directly onto meshes.
  • Modeling Mode — Edit and create geometry directly in the editor.

We'll explore Landscape and Foliage modes in detail in later lessons.

Understanding Actors

In Unreal Engine, everything you place in a level is an Actor. A cube? Actor. A light? Actor. A sound emitter? Actor. A camera? Actor. Even the Player Start (the spot where the player spawns) is an Actor.

Actors are made up of Components. A typical mesh actor has:

  • A Static Mesh Component — the visible 3D shape
  • A Collision Component — the invisible shape used for physics/overlap detection
  • A Scene Component (Root) — defines the actor's position in 3D space

This component-based design is extremely flexible. Want a lamp that emits light and plays a buzzing sound? Add a Point Light component and an Audio component to a mesh actor. No coding required.

Tip: You can customize the editor layout to fit your workflow. Drag panel tabs to rearrange them, dock panels side-by-side, or pop them out into separate windows. Once you have a layout you like, save it via Window → Save Layout so you can restore it anytime.

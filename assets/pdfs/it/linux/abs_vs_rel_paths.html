Introduction to Linux

Absolute vs. Relative Paths

Understanding how Linux locates files and directories

What Is a Path?

A path is the address of a file or directory in the Linux filesystem. Every file on your system has a unique path that describes exactly where it lives. Think of it like a mailing address — it tells the system how to find something.

There are two ways to express a path in Linux: absolute paths and relative paths.

The Linux Filesystem Tree

Before we dive in, let's understand the structure. Linux organizes everything in a tree-like hierarchy. The very top of the tree is called the root directory, and it's represented by a single forward slash: /

Everything branches out from there:

/
├── home/
│   ├── alice/
│   │   ├── Documents/
│   │   │   └── essay.txt
│   │   └── Downloads/
│   └── bob/
├── etc/
├── var/
└── usr/

Absolute Paths

An absolute path always starts from the root directory (/). It spells out the complete route from the very top of the filesystem tree to the target file or directory. No matter where you currently are in the filesystem, an absolute path will always point to the same location.

Key Rule: If a path starts with /, it's an absolute path.

Examples

# The full path to alice's essay
/home/alice/Documents/essay.txt

# The full path to the system configuration directory
/etc

# The full path to alice's home directory
/home/alice

It doesn't matter if you're currently in /var, /tmp, or /home/bob. The command below will always open essay.txt in alice's Documents folder:

cat /home/alice/Documents/essay.txt

Relative Paths

A relative path describes how to get to a file or directory from where you currently are. It does not start with /. Instead, it uses the current working directory as the starting point.

Key Rule: If a path does not start with /, it's a relative path.

Examples

Suppose your current working directory is /home/alice:

# These two commands do the same thing:
cat /home/alice/Documents/essay.txt    # absolute
cat Documents/essay.txt                # relative

The relative path Documents/essay.txt only works because you're already in /home/alice. If you were in /home/bob, that relative path would look for /home/bob/Documents/essay.txt instead — which may not exist!

Special Path Symbols

Linux provides several shortcut symbols to make navigating the filesystem easier:

Symbol Meaning Example
. Current directory ./script.sh (run a script in the current directory)
.. Parent directory (one level up) cd .. (go up one folder)
~ Home directory of the current user cd ~ (go to your home directory)
- Previous directory (with cd) cd - (go back to where you were)

Using .. to Navigate Up

The .. symbol is one of the most useful navigation tools. You can chain them together to move up multiple levels:

# Currently in /home/alice/Documents/Projects
cd ..          # Now in /home/alice/Documents
cd ../..       # Now in /home/alice (went up two levels)
cd ../../bob   # Now in /home/bob (up two, then into bob)

Using ~ as a Shortcut

The tilde (~) is a convenient shortcut for your home directory:

# These do the same thing (if you're user "alice"):
cd /home/alice
cd ~

# Access a file in your home directory from anywhere:
cat ~/Documents/essay.txt

Checking Your Current Location

Use the pwd command (print working directory) to find out where you are at any time:

$ pwd
/home/alice/Documents

This is especially helpful when you're using relative paths and want to confirm your starting point.

When to Use Which?

Use Absolute Paths When...

  • Writing scripts that need to work no matter where they're run from
  • Referencing system files like /etc/hosts or /var/log/syslog
  • You want to be 100% certain you're targeting the right file
  • Giving someone a path to follow (documentation, instructions)

Use Relative Paths When...

  • You're already close to the file you want to access
  • Navigating between nearby directories (cd ../sibling-folder)
  • Working inside a project where file locations are consistent
  • You want shorter, more convenient commands

Practice Examples

Given this directory tree:

/home/student/
├── Music/
│   └── song.mp3
├── Projects/
│   ├── app/
│   │   └── main.py
│   └── notes.txt
└── Downloads/
    └── file.zip

If your current directory is /home/student/Projects/app:

Target Absolute Path Relative Path
main.py /home/student/Projects/app/main.py main.py or ./main.py
notes.txt /home/student/Projects/notes.txt ../notes.txt
song.mp3 /home/student/Music/song.mp3 ../../Music/song.mp3
file.zip /home/student/Downloads/file.zip ../../Downloads/file.zip

Try It Yourself

  1. Open your terminal and run pwd to see where you are.
  2. Use cd with an absolute path to navigate to /tmp.
  3. Run pwd again to confirm.
  4. Use cd ~ to jump back to your home directory.
  5. Navigate to a subfolder using a relative path, then use cd .. to come back.
  6. Use cd - to toggle between your last two locations.

Key Takeaways

  • Absolute paths start with / and always point to the same location.
  • Relative paths depend on your current working directory.
  • Use pwd to check where you are.
  • Use .. to move up, ~ to jump home, and - to go back.
  • Both types of paths are useful — choose the one that fits the situation.

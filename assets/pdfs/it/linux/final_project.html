Introduction to Linux

Final Project: Linux Task Challenge

Put your skills to the test with this hands-on Linux challenge

Overview

Congratulations on making it to the final project! This challenge will test everything you've learned in this course. You'll complete a series of tasks that cover the terminal, file management, permissions, system monitoring, and user management.

Where to Complete This: You can complete this project in either WSL (Windows Subsystem for Linux) or your Ubuntu VirtualBox VM. Choose whichever environment you're most comfortable with.

Instructions

  • Complete each task in order.
  • After each task, take a screenshot or copy/paste your terminal output to document your work.
  • If you get stuck, revisit the relevant reading material or ask your instructor.
  • You may use man pages, --help flags, and your course notes — this is open-resource!

Part 1: Navigation & File Management

Task 1: Create a Project Structure

Create the following directory structure inside your home directory:

~/linux-challenge/
├── documents/
│   ├── notes/
│   └── reports/
├── scripts/
└── logs/

Hint: You can create nested directories with mkdir -p.

Task 2: Create and Populate Files

  1. Navigate into ~/linux-challenge/documents/notes/
  2. Create a file called day1.txt containing the text: "Today I learned how to navigate the Linux filesystem."
  3. Create a file called day2.txt containing the text: "Today I learned about file permissions and ownership."
  4. Create a file called day3.txt containing the text: "Today I learned how to manage users and groups."

Hint: Use echo "text" > filename to create files with content.

Task 3: Copy, Move, and Organize

  1. Copy all three day files to the reports/ directory.
  2. In the reports/ directory, combine all three files into one file called weekly_summary.txt.
  3. Verify the contents of weekly_summary.txt using cat.

Hint: Use cat file1 file2 file3 > combined to combine files.

Part 2: Scripting

Task 4: Write a Shell Script

  1. Navigate to ~/linux-challenge/scripts/
  2. Create a file called sysinfo.sh with the following content:
#!/bin/bash
echo "=== System Information ==="
echo "Hostname: $(hostname)"
echo "User: $(whoami)"
echo "Date: $(date)"
echo "Uptime: $(uptime -p)"
echo ""
echo "=== Disk Usage ==="
df -h /
echo ""
echo "=== Memory Usage ==="
free -h
echo ""
echo "=== Top 5 Processes by CPU ==="
ps aux --sort=-%cpu | head -6
  1. Make the script executable.
  2. Run the script and verify it works.
  3. Redirect the output of the script to ~/linux-challenge/logs/sysinfo.log

Hint: Use chmod +x to make it executable. Use > to redirect output to a file.

Part 3: Permissions

Task 5: Set File Permissions

  1. Set sysinfo.sh so that:
    • The owner can read, write, and execute
    • The group can read and execute
    • Others have no permissions
  2. Verify the permissions with ls -l.
  3. What is the numeric (octal) value for these permissions?

Task 6: Create a Private Directory

  1. Create a directory called ~/linux-challenge/private/
  2. Set its permissions so that only you (the owner) can read, write, and enter it.
  3. Create a file inside it called secret.txt with a message of your choice.
  4. Verify that the directory permissions are correct with ls -la ~/linux-challenge/

Part 4: User Management

Task 7: Create a User and Group

  1. Create a new group called challengers.
  2. Create a new user called testuser.
  3. Add testuser to the challengers group.
  4. Verify the group membership with the groups command.
  5. Switch to the testuser account and run whoami to confirm.
  6. Switch back to your account with exit.

Part 5: System Monitoring

Task 8: Monitor and Report

  1. Run htop (install it if needed) and take a screenshot showing the process list.
  2. Use df -h to check disk usage and note which filesystem is most full.
  3. Use free -h to check memory usage and note the total and available memory.
  4. Start a background process: sleep 600 &
  5. Find the PID of the sleep process using ps aux | grep sleep.
  6. Kill the sleep process.
  7. Verify it's gone with ps aux | grep sleep.

Part 6: Troubleshooting Challenge

Task 9: Fix the Broken Script

Create a file called ~/linux-challenge/scripts/broken.sh with this content:

#!/bin/bash
EHCO "Starting system check..."
dat
whoam
df -h | Grep "/"
echo "Check complete!"
  1. Try to run this script. It will have errors.
  2. Identify and fix each error in the script.
  3. Run the corrected script to verify it works.

Hint: There are 4 errors. Pay attention to spelling and case sensitivity!

Cleanup

Task 10: Clean Up

  1. Delete the testuser account and their home directory.
  2. Delete the challengers group.
  3. Optionally, remove the ~/linux-challenge/ directory (or keep it as a reference!).

Submission

Submit the following to your instructor:

  1. Screenshots or terminal output for each task
  2. Your corrected broken.sh script
  3. The sysinfo.log file from Task 4
  4. A brief paragraph: What was the most challenging part of this project, and what did you learn?

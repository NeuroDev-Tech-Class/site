User and Group Management

Creating users, managing groups, and switching accounts in Linux

Why Users and Groups?

Linux is designed for multiple people to use the same machine, each with their own files, settings, and permissions. The system uses users and groups to organize who can access what.

  • A user is an account on the system — it could be a person or a service (like a web server).
  • A group is a collection of users who share certain access rights.

Important System Users

Linux has some special built-in users:

User Purpose
root The superuser/administrator. Has unrestricted access to everything. User ID (UID) is always 0.
Your username The account you created during setup. Can use sudo to perform admin tasks.
nobody A restricted account used by some services to limit access.
Who am I? Run the whoami command at any time to see which user you're currently logged in as. Run id to see your user ID, group ID, and all groups you belong to.

Viewing User Information

# Who am I?
$ whoami
alice

# Full user/group information
$ id
uid=1000(alice) gid=1000(alice) groups=1000(alice),27(sudo),1001(students)

# List all users on the system (one per line in /etc/passwd)
$ cat /etc/passwd

# See just the usernames
$ cut -d: -f1 /etc/passwd

Understanding /etc/passwd

The /etc/passwd file stores basic info about every user. Each line looks like:

alice:x:1000:1000:Alice Smith:/home/alice:/bin/bash

The fields are separated by colons:

Field Example Meaning
1aliceUsername
2xPassword placeholder (actual password is in /etc/shadow)
31000User ID (UID)
41000Primary Group ID (GID)
5Alice SmithFull name / description
6/home/aliceHome directory
7/bin/bashDefault shell

Creating a New User

Use the adduser command (the friendlier option) or useradd (the lower-level command):

# The easy way (interactive, sets up home directory automatically)
sudo adduser bob

# It will prompt you for:
# - Password
# - Full name
# - Other optional info

What adduser does behind the scenes:

  1. Creates the user account
  2. Creates a home directory at /home/bob
  3. Copies default config files (like .bashrc) into the home directory
  4. Creates a group with the same name as the user
  5. Sets the password

Deleting a User

# Remove the user (keeps their home directory)
sudo deluser bob

# Remove the user AND their home directory
sudo deluser --remove-home bob
Be careful with --remove-home! This permanently deletes all the user's files. Make sure you don't need them before running this command.

Managing Groups

Viewing Groups

# See which groups you belong to
$ groups
alice sudo students

# See groups for a specific user
$ groups bob

# List all groups on the system
$ cat /etc/group

Creating a Group

sudo addgroup developers

Adding a User to a Group

# Add bob to the "developers" group
sudo usermod -aG developers bob
The -aG flags are important!
  • -a means append — add to the group without removing from other groups
  • -G specifies the group to add to
Without -a, the user would be removed from all their other groups! Always use -aG together.

Removing a User from a Group

sudo deluser bob developers

Deleting a Group

sudo delgroup developers

Switching Users

You can switch to another user account with the su (switch user) command:

# Switch to user "bob" (you'll need bob's password)
su bob

# Switch to user "bob" and load their environment
su - bob

# Switch to root (the superuser)
sudo su

# Go back to your original user
exit
su vs. su -
su bob switches to bob but keeps your current environment (directory, variables).
su - bob switches to bob and loads bob's environment — like a fresh login. The - version is usually what you want.

The sudo Group

On Ubuntu, users in the sudo group can run commands as root using sudo. If you created the first user during Ubuntu installation, that user is automatically in the sudo group.

# Check if a user can use sudo
groups alice
# alice : alice sudo students  ← "sudo" appears in the list

# Give another user sudo access
sudo usermod -aG sudo bob

Setting and Changing Passwords

# Change your own password
passwd

# Change another user's password (requires sudo)
sudo passwd bob

# Force a user to change their password on next login
sudo passwd -e bob

Try It Yourself

  1. Run whoami and id to see your current user info.
  2. Run groups to see which groups you belong to.
  3. Create a new user: sudo adduser testuser
  4. Switch to that user: su - testuser
  5. Run whoami to confirm you've switched, then type exit to return.
  6. Create a group: sudo addgroup myteam
  7. Add the test user to the group: sudo usermod -aG myteam testuser
  8. Verify: groups testuser
  9. Clean up: sudo deluser --remove-home testuser and sudo delgroup myteam

Introduction to Linux

System Monitoring Tools

Keeping an eye on your system with top, htop, and friends

Why Monitor Your System?

Just like a car dashboard shows you speed, fuel, and engine temperature, Linux has tools that show you what's happening inside your computer. System monitoring helps you:

  • Find out which programs are using the most CPU or memory
  • Identify processes that are frozen or misbehaving
  • Check how much RAM and swap space are in use
  • Understand system load and performance
  • Troubleshoot slowdowns and high resource usage

Processes: The Basics

Every program running on your Linux system is called a process. Each process has:

  • PID — Process ID, a unique number identifying the process
  • User — The user account running the process
  • CPU % — How much of the processor it's using
  • MEM % — How much memory (RAM) it's using
  • Command — The name of the program or command

top — The Classic System Monitor

The top command is the built-in, real-time system monitor. It's available on virtually every Linux system.

top

When you run top, you'll see a screen like this:

Understanding the Header

Line What It Shows
top Current time, uptime, number of users, and load average
Tasks Total processes and their states (running, sleeping, stopped, zombie)
%Cpu(s) CPU usage breakdown (us=user, sy=system, id=idle, wa=waiting)
MiB Mem Physical RAM usage (total, free, used, cached)
MiB Swap Swap space usage (disk space used as backup memory)

htop — The Improved System Monitor

htop is a more user-friendly and colorful version of top. It provides the same information but with a much nicer interface.

Installing htop

sudo apt install htop

Running htop

htop

What Makes htop Better?

  • Color-coded — CPU and memory bars use colors to show usage at a glance
  • Mouse support — You can click on columns to sort, click on processes to select them
  • Scrolling — Use arrow keys to scroll through all processes (top only shows what fits on screen)
  • Tree view — Press F5 to see processes organized by parent/child relationships
  • Easy kill — Select a process and press F9 to send it a signal
  • Search — Press F3 to search for a process by name
  • Filter — Press F4 to filter the process list
htop Keyboard Guide: The bottom of the htop screen always shows the available function key shortcuts (F1–F10), making it very beginner-friendly!

Other Useful Monitoring Commands

free — Check Memory Usage

A quick way to see how much RAM is being used:

$ free -h
               total        used        free      shared  buff/cache   available
Mem:           7.7Gi       3.4Gi       2.1Gi       256Mi       2.2Gi       3.9Gi
Swap:          2.0Gi          0B       2.0Gi

The -h flag shows values in human-readable format (GB, MB instead of bytes).

df — Check Disk Space

See how much storage space is used on each drive:

$ df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   22G   26G  46% /
tmpfs           3.9G  1.2M  3.9G   1% /dev/shm

du — Check Directory Size

Find out how much space a specific directory is using:

# Show the total size of a directory
du -sh ~/Documents
# 1.2G    /home/alice/Documents

# Show sizes of all subdirectories
du -h --max-depth=1 ~/Documents

uptime — How Long Has the System Been Running?

$ uptime
 14:30:22 up 3 days,  2:15,  1 user,  load average: 0.52, 0.38, 0.41

The three load average numbers represent system load over the last 1, 5, and 15 minutes. For a single-core CPU, a load of 1.0 means it's fully utilized.

Killing Processes

Sometimes a program freezes or uses too many resources. You can stop it using the kill command:

# First, find the process ID (PID)
ps aux | grep firefox

# Kill it gracefully (asks it to close)
kill 1234

# Force kill it (immediately terminate)
kill -9 1234

You can also use killall to kill processes by name:

# Kill all instances of firefox
killall firefox
Use kill -9 as a last resort! The -9 flag (SIGKILL) forces a process to stop immediately without giving it a chance to save data or clean up. Always try a regular kill (SIGTERM) first, and only use -9 if the process refuses to stop.

Try It Yourself

  1. Run top and observe the output. Press M to sort by memory, then q to quit.
  2. Install htop: sudo apt install htop
  3. Run htop and explore the interface. Try pressing F5 for tree view.
  4. Run free -h to see your current memory usage.
  5. Run df -h to see your disk space.
  6. Open a second terminal tab, run sleep 300 & to create a background process, then find and kill it using ps aux | grep sleep and kill.
